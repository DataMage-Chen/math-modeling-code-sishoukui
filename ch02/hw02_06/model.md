# 习题 2.6 模型（整数线性规划）

## 题意重述
求解如下整数线性规划问题：

`min Z = 20x1 + 90x2 + 80x3 + 70x4 + 30x5`

约束：

1. `x1 + x2 + x3 >= 30`
2. `x3 + x4 >= 30`
3. `3x1 + 2x3 <= 120`
4. `3x2 + 2x4 + x5 <= 48`
5. `xj >= 0` 且为整数，`j=1,2,3,4,5`

## 决策变量
- `x1, x2, x3, x4, x5`：非负整数决策变量。

## 目标函数
- 最小化总成本 `Z`。

## 约束条件
- 两条需求下限约束（前两条）；
- 两条资源上限约束（第三、四条）；
- 变量整数与非负约束。

## 说明
- 该模型是标准 ILP（整数线性规划），可由 Gurobi 直接精确求解。
