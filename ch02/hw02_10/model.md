# 习题 2.10 模型（三阶段流水面试排序）

## 题意重述
有 4 名同学（甲、乙、丙、丁）参加公司三阶段面试：

1. 秘书初试  
2. 主管复试  
3. 经理面试

每名同学必须按上述顺序依次完成三阶段，且不允许插队，即三阶段中的面试顺序完全一致（排列流水车间 / permutation flow shop）。

已知各同学在三阶段的面试时长（分钟）：

- 甲：`(14, 16, 21)`
- 乙：`(19, 17, 10)`
- 丙：`(10, 15, 12)`
- 丁：`(9, 12, 13)`

当前时间为早上 8:00，求最早何时全部结束并离开公司。

## 决策变量
- `y_{i,k} in {0,1}`：同学 `i` 是否排在第 `k` 个面试。
- `C_{k,m} >= 0`：第 `k` 个同学在第 `m` 个阶段的完成时刻（单位：分钟，起点为 8:00）。

其中：
- `i=1..4`（甲、乙、丙、丁）
- `k=1..4`（排序位置）
- `m=1..3`（三阶段）

## 目标函数
最小化最后一名同学在第三阶段完成时刻（总完工时间）：

`min Z = C_{4,3}`

## 约束条件
1. 每名同学恰好占一个位置：  
   `sum_k y_{i,k} = 1`
2. 每个位置恰好安排一名同学：  
   `sum_i y_{i,k} = 1`
3. 同阶段先后顺序约束（同一阶段不能重叠）：  
   `C_{k,m} >= C_{k-1,m} + p_{k,m}`
4. 同一同学跨阶段工艺顺序约束：  
   `C_{k,m} >= C_{k,m-1} + p_{k,m}`
5. 非负与二进制约束：  
   `C_{k,m} >= 0`，`y_{i,k} in {0,1}`

其中 `p_{k,m}` 由位置-人员映射给出：

`p_{k,m} = sum_i t_{i,m} * y_{i,k}`

## 说明
- 该模型是标准的“排列流水作业调度”MILP建模。
- 目标值单位为分钟；若 `Z=82`，则离开时间为 `8:00 + 82 min = 9:22`。
