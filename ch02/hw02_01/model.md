# 习题 2.1 模型（非线性 0-1 规划线性化）

## 题意重述
将下列非线性的 0-1 规划问题转化为线性的 0-1 规划，并求解：

- `max z = x1 + x1*x2 - x3`
- `s.t. -2x1 + 3x2 + x3 <= 3`
- `xj = 0 或 1, j=1,2,3`

## 决策变量
- 原变量：`x1, x2, x3 ∈ {0,1}`
- 辅助变量：`y ∈ {0,1}`，用于替代乘积项 `x1*x2`

## 目标函数
- 线性化后目标：
  `max z = x1 + y - x3`

## 约束条件
原约束保留：

1. `-2x1 + 3x2 + x3 <= 3`

乘积项 `y = x1*x2` 的线性化约束：

2. `y <= x1`
3. `y <= x2`
4. `y >= x1 + x2 - 1`
5. `x1, x2, x3, y ∈ {0,1}`

## 说明
- 对于 0-1 变量，以上三条不等式可精确刻画 `y = x1*x2`，因此该线性化是等价变换。
- 线性化后模型是标准 0-1 整数规划（MILP），可直接用 Gurobi 求解。
