# 例题 2.10 模型（比赛项目顺序优化）

## 题意重述
某小型运动会有 14 个比赛项目、40 名运动员。已知报名表（40×14 的 0-1 矩阵），其中 `a_{m,i}=1` 表示运动员 `m` 参加项目 `i`。  
需要安排 14 个项目的比赛顺序，使“连续参加两项比赛”的运动员人次尽可能少。

## 决策变量
- `x_{i,j} ∈ {0,1}`：若排序路径中存在“项目 `i` 后紧接项目 `j`”，则取 1，否则取 0。  
  这里将真实项目记为 `1..14`，并额外引入虚拟项目 `15`（起终点辅助节点）。
- `u_i`：项目 `i (1..14)` 在巡回中的次序变量（MTZ 去子回路变量）。

## 目标函数
先定义任意两个项目的“冲突权重”：

`w_{i,j} = Σ_{m=1}^{40} a_{m,i} a_{m,j}`（表示同时报名项目 `i,j` 的人数，`i≠j`）。

虚拟项目与任意真实项目之间权重取 0。最小化总相邻冲突：

`min z = Σ_{i=1}^{15} Σ_{j=1, j≠i}^{15} w_{i,j} x_{i,j}`。

这等价于最小化连续参赛的总人次。

## 约束条件
1. 每个节点有且仅有一条流出边：  
   `Σ_{j≠i} x_{i,j} = 1,  i=1..15`
2. 每个节点有且仅有一条流入边：  
   `Σ_{i≠j} x_{i,j} = 1,  j=1..15`
3. MTZ 去子回路约束（仅对真实项目）：  
   `u_i - u_j + 14 x_{i,j} ≤ 13,  i≠j, i,j∈{1..14}`
4. 次序变量取值范围：  
   `1 ≤ u_i ≤ 14`
5. 二进制约束：  
   `x_{i,j} ∈ {0,1}`

## 说明
- 该问题本质是**最小权哈密顿路径**：在带权图中找一条经过每个项目恰好一次的路径，并使路径总权重最小。这里的边权就是“两个项目相邻时造成的连续参赛人次”。
- 最小权哈密顿路径与 TSP（最小权哈密顿回路）非常接近。为使用标准 TSP 建模，可加入虚拟项目 15，并令其与各项目边权为 0；这样求得回路后，去掉虚拟项目即可还原为原问题的最优路径顺序。
- 本题目标是最小化“人次”，不是最小化“人数”。若同一运动员连续参加三项，他会贡献两次连续参赛人次。
- 该类模型通常存在多个最优顺序；不同顺序的决策变量可能不同，但最优目标值相同。
