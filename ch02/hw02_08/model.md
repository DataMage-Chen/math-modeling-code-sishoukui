# 习题 2.8 模型（标准指派问题）

## 题意重述
求解标准指派问题，给定 6x6 指派成本矩阵：

`C = [[6, 7, 5, 8, 9, 10],`
`     [6, 3, 7, 9, 3, 8],`
`     [8, 11, 12, 6, 7, 9],`
`     [9, 7, 5, 4, 7, 6],`
`     [5, 8, 9, 6, 10, 7],`
`     [9, 8, 7, 6, 5, 9]]`

要求每个任务恰好分配给一个人、每个人恰好执行一个任务，使总成本最小。

## 决策变量
- `x_{i,j} in {0,1}`：若第 `i` 个执行者分配到第 `j` 个任务，则取 1；否则取 0。

## 目标函数
- 最小化总指派成本：

`min Z = sum_i sum_j c_{i,j} * x_{i,j}`

## 约束条件
1. 每个执行者恰好分配一个任务：`sum_j x_{i,j} = 1`
2. 每个任务恰好由一个执行者执行：`sum_i x_{i,j} = 1`
3. 二进制约束：`x_{i,j} in {0,1}`

## 说明
- 这是经典 0-1 线性规划指派模型（Assignment Problem）。
- 该模型对应二分图完美匹配的最小权问题，可精确求解。
