# 习题 2.2 模型（集合覆盖）

## 题意重述
某市在 8 个居民小区 `A1..A8` 周边有 6 个备选校址 `B1..B6`，其覆盖关系如下：

- `B1` 覆盖 `A1, A5, A7`
- `B2` 覆盖 `A1, A2, A5, A8`
- `B3` 覆盖 `A1, A3, A5`
- `B4` 覆盖 `A2, A4, A8`
- `B5` 覆盖 `A3, A6`
- `B6` 覆盖 `A4, A6, A8`

要求建立模型，选出最少数量的校址，使全部小区都被覆盖。

## 决策变量
- `y_j ∈ {0,1}`：是否选择备选校址 `Bj`。  
  `y_j=1` 表示建校，`y_j=0` 表示不建校。

## 目标函数
- 最小化建校数量：

`min z = y1 + y2 + y3 + y4 + y5 + y6`

## 约束条件
对每个小区，至少被一个被选校址覆盖：

1. `A1`: `y1 + y2 + y3 >= 1`
2. `A2`: `y2 + y4 >= 1`
3. `A3`: `y3 + y5 >= 1`
4. `A4`: `y4 + y6 >= 1`
5. `A5`: `y1 + y2 + y3 >= 1`
6. `A6`: `y5 + y6 >= 1`
7. `A7`: `y1 >= 1`
8. `A8`: `y2 + y4 + y6 >= 1`

以及二进制约束：`y_j ∈ {0,1}, j=1..6`。

## 说明
- 这是标准的 0-1 集合覆盖问题（Set Covering）。
- 由约束 `A7: y1 >= 1` 可知 `B1` 必选；在此基础上再覆盖 `A2,A4,A8` 与 `A3,A6`，最优可取 `B4` 与 `B5`，因此最优建校数为 3。
