# 习题 2.7 模型（家电产品生产计划）

## 题意重述
某公司计划每天生产 I、II 两种家电产品。  
每生产 1 件产品对设备与工序的占用、以及每天可用能力如下：

- 设备 A（小时）：I 用 0，II 用 5；每天可用 15
- 设备 B（小时）：I 用 6，II 用 2；每天可用 24
- 调试工序（小时）：I 用 1，II 用 1；每天可用 5
- 单件利润（元）：I 为 2，II 为 1

求每天两种产品各生产多少件，才能使利润最大。

## 决策变量
- `x1`：产品 I 的日产量（非负整数）
- `x2`：产品 II 的日产量（非负整数）

## 目标函数
- 最大化总利润：

`max Z = 2*x1 + 1*x2`

## 约束条件
1. 设备 A 能力：`5*x2 <= 15`
2. 设备 B 能力：`6*x1 + 2*x2 <= 24`
3. 调试工序能力：`x1 + x2 <= 5`
4. 非负整数：`x1, x2 >= 0` 且为整数

## 说明
- 本题按整数生产量建模为 ILP。
- 该模型存在多个最优整数解（不同方案利润可相同）。
