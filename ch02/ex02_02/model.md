# 例题 2.2 模型（标准指派问题）

## 题意重述
某单位有 `n` 项任务，恰好需要 `n` 个人完成。  
每个人只能完成一项任务，每项任务也只能由一人完成。  
设 `c_ij` 为“第 `i` 个人完成第 `j` 项任务的费用（或时间）”，目标是使总费用最小。

## 决策变量
- `x_ij ∈ {0,1}`：是否将第 `j` 项任务分配给第 `i` 个人。
  - `x_ij = 1`：分配；
  - `x_ij = 0`：不分配。

## 目标函数
- 最小化总费用：
  - `min z = sum_i sum_j c_ij * x_ij`

## 约束条件
1. 每个人恰好执行一项任务：
   - `sum_j x_ij = 1`，`i=1,2,...,n`
2. 每项任务恰好分配给一人：
   - `sum_i x_ij = 1`，`j=1,2,...,n`
3. 二元约束：
   - `x_ij ∈ {0,1}`

## 说明
- 本题是典型 0-1 整数规划（MIP）；
- 原题为一般形式，代码在开头给出一组示例成本矩阵并据此求解。
