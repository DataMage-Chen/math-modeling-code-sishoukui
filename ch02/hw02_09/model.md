# 习题 2.9 模型（运输优化）

## 题意重述
有 8 个配送中心可供货，15 个部队用户有需求。已知：

- 单位运输费用 `c_{i,j}`（用户 `i` 由中心 `j` 供货的单位运费）；
- 用户需求量 `d_i`；
- 配送中心储备量 `s_j`。

要求：
1. 根据给定数据，求最小运费调配计划；
2. 增加约束：配送中心 `j` 对用户 `i` 要么不配送，要配送则配送量在 `[1000, 2000]`，求最小费用计划。

## 决策变量
### 第(1)问
- `x_{i,j} >= 0`：中心 `j` 配送给用户 `i` 的数量。

### 第(2)问
- `x_{i,j} >= 0`：同上；
- `y_{i,j} in {0,1}`：是否启用“中心 `j` -> 用户 `i`”这条配送关系。

## 目标函数
两问目标一致，均为最小化总运输费用：

`min Z = sum_i sum_j c_{i,j} * x_{i,j}`

## 约束条件
### 两问共同约束
1. 每个用户需求必须满足：`sum_j x_{i,j} = d_i`
2. 每个中心发货不超过储备：`sum_i x_{i,j} <= s_j`
3. 非负性：`x_{i,j} >= 0`

### 第(2)问额外约束
“要么不送，要送则在 [1000, 2000]”用大 M 方式线性化：

4. `x_{i,j} <= 2000 * y_{i,j}`
5. `x_{i,j} >= 1000 * y_{i,j}`
6. `y_{i,j} in {0,1}`

## 说明
- 第(1)问是线性规划（LP）运输问题；
- 第(2)问是混合整数线性规划（MILP）；
- 由于总储备远大于总需求，供给约束采用“<=”而非“=”。
