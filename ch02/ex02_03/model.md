# 例题 2.3 模型（旅行商问题）

## 题意重述
有一位推销员从城市 `v1` 出发，需遍访其余城市各一次，最后回到 `v1`。  
已知城市 `vi` 到城市 `vj` 的旅费为 `c_ij`，求访问顺序使总旅费最小。

## 决策变量
- `x_ij ∈ {0,1}`：是否从城市 `vi` 直接前往城市 `vj`（`i != j`）。
  - `x_ij = 1` 表示采用该弧；
  - `x_ij = 0` 表示不采用。

为消除子回路，引入 MTZ 辅助变量：

- `u_i`：城市访问顺序变量（对起点外城市定义）。

## 目标函数
- 最小化总旅费：
  - `min z = sum_i sum_{j!=i} c_ij * x_ij`

## 约束条件
1. 每个城市恰好有一条出边：
   - `sum_{j!=i} x_ij = 1`
2. 每个城市恰好有一条入边：
   - `sum_{i!=j} x_ij = 1`
3. MTZ 去子环约束（设城市 1 为起点）：
   - `u_i - u_j + (n-1)*x_ij <= n-2`，`i,j=2,...,n, i!=j`
4. 二元与边界约束：
   - `x_ij ∈ {0,1}`
   - `1 <= u_i <= n-1`

## 说明
- 本题是经典 0-1 整数规划（MIP）；
- 代码开头定义了参数化示例数据生成方式：给定城市数量 `n` 与随机种子 `seed`，生成一组对称旅费矩阵并据此求解；
- 脚本支持命令行参数 `--n`、`--seed`，可用于观察规模变化对求解速度的影响。
- 经典优化算法在TSP上已极其成熟，精确求解的实用上限约为3,000-10,000个城市，而启发式算法可处理百万级城市并保持高质量。量子计算在该问题上目前仅具理论意义，尚未达到实用规模。
