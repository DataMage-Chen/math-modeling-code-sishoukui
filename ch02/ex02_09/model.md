# 例题 2.9 模型（非线性整数规划）

## 题意重述
求解如下非线性整数规划问题：

- 最大化  
  `z = x1^2 + x2^2 + 3x3^2 + 4x4^2 + 2x5^2 - 8x1 - 2x2 - 3x3 - x4 - 2x5`

约束条件：

- `0 <= x_i <= 99`，`i=1,2,3,4,5`
- `x1 + x2 + x3 + x4 + x5 <= 400`
- `x1 + 2x2 + 2x3 + x4 + 6x5 <= 800`
- `2x1 + x2 + 6x3 <= 200`
- `x3 + x4 + 5x5 <= 200`
- `x_i` 为整数

## 决策变量
- `x1, x2, x3, x4, x5`：整数决策变量，满足 `0 <= x_i <= 99`。

## 目标函数
- 最大化二次函数 `z`（非线性目标）。

## 约束条件
1. 变量范围与整数性约束；
2. 4 条线性不等式资源约束。

## 求解思路
本题在代码中使用两种方法并对比误差：

1. 蒙特卡洛法（随机可行采样）  
   - 随机生成大量可行整数点；
   - 记录其中目标值最大的样本点，作为近似解。

2. 精确求解（Gurobi MIQP）  
   - 将问题作为混合整数二次规划（MIQP）求解；
   - 得到全局最优解（在求解器容差内）。

最后比较蒙特卡洛近似解与精确解在目标值上的绝对误差和相对误差。

## 说明
- 蒙特卡洛样本数越大，近似解通常越接近精确最优；
- 该题为整数非线性优化，精确求解速度依赖求解器与参数设置。
