# 习题 2.5 模型（钢条下料优化 / Cutting Stock）

## 题意重述
需要加工 100 套钢架。每套需要长度为 `2.9m`、`2.1m`、`1.0m` 的圆钢各 1 根。  
原料钢条长度为 `6.9m`。求：

1. 如何下料使使用的原料根数最少；
2. 若下料方式（切割模式）不超过 3 种，如何下料使原料根数最少。

## 决策变量
先定义“下料方式（切割模式）” `p`：一根 6.9m 钢条切出
`(a_p, b_p, c_p)` 根三类零件，满足

`2.9*a_p + 2.1*b_p + 1.0*c_p <= 6.9`

并取“不可再加入任一零件”的极大模式（代码自动枚举）。

- `x_p`：采用模式 `p` 的原料根数，`x_p` 为非负整数。
- 第(2)问再引入 `y_p in {0,1}`：模式 `p` 是否被使用。

## 目标函数
最小化原料总根数：

`min Z = sum_p x_p`

## 约束条件
设三类零件需求均为 100 根，则：

1. `sum_p a_p * x_p >= 100`
2. `sum_p b_p * x_p >= 100`
3. `sum_p c_p * x_p >= 100`

第(2)问额外约束：

4. `x_p <= M * y_p`（联动约束）
5. `sum_p y_p <= 3`（最多 3 种下料方式）

其中 `M` 为足够大的常数（代码中取 300）。

## 说明
- 这是标准整数线性规划（ILP）切割库存模型。
- 代码同时输出：
  - 最少原料根数；
  - 每种下料方式使用次数；
  - 三类零件的产出与需求对比；
  - 总利用率与总余料长度。
