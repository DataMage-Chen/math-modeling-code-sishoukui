# 例题 6.14 模型（阿波罗卫星轨道方程数值求解）

## 题意重述
已知阿波罗卫星在旋转坐标系下的运动轨迹 `(x(t),y(t))` 满足：

- `x'' = 2y' + x - lambda*(x+mu)/r1^3 - mu*(x-lambda)/r2^3`
- `y'' = -2x' + y - lambda*y/r1^3 - mu*y/r2^3`

其中：

- `mu = 1/82.45`
- `lambda = 1 - mu`
- `r1 = sqrt((x+mu)^2 + y^2)`
- `r2 = sqrt((x+lambda)^2 + y^2)`（按教材给定公式）

初值为：

- `x(0)=1.2`
- `x'(0)=0`
- `y(0)=0`
- `y'(0)=-1.0494`

要求求解并绘制轨迹图。

## 已知数据与符号说明
- `x,y`：卫星在旋转坐标系中的位置
- `vx=x', vy=y'`：速度分量
- `r1,r2`：卫星到两主天体的距离
- 参数 `mu,lambda`：由两主天体质量比决定

## 数学模型
将二阶方程组改写为一阶系统，令状态向量：

- `z = [x, vx, y, vy]^T`

则：

- `x'  = vx`
- `vx' = 2*vy + x - lambda*(x+mu)/r1^3 - mu*(x-lambda)/r2^3`
- `y'  = vy`
- `vy' = -2*vx + y - lambda*y/r1^3 - mu*y/r2^3`

其中：

- `r1 = sqrt((x+mu)^2 + y^2)`
- `r2 = sqrt((x+lambda)^2 + y^2)`

## 数值求解方法
- 使用 `scipy.integrate.solve_ivp` 在给定时间区间上积分；
- 取较小误差容差（`rtol, atol`）提高轨道积分精度；
- 输出轨道关键统计（如最小 `r1,r2`、末状态）。

> 注：本题严格按教材中给出的方程形式实现（包含 `r2` 的写法与对应分量公式），
> 以复现教材图 6.7 轨道形态。

## 结果与校验
- 绘制 `(x(t),y(t))` 轨迹曲线；
- 与教材一致，默认取积分区间 `t∈[0,100]`，可得到螺旋状轨迹图。
