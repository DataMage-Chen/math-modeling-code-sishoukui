# 例题 6.16 模型（含参数的线性边值问题）

## 题意重述
求解边值问题：

- `y''(x) + mu*y(x) = 0, x ∈ [0,1]`
- `y(0)=0`
- `y'(0)=1`
- `y(1)+y'(1)=0`

其中 `mu` 为未知参数。

## 已知数据与符号说明
- `y(x)`：绳的位移函数
- `mu`：待求参数（与系统模态相关）
- 条件 `y'(0)=1` 是归一化条件，用来固定特征函数幅值

## 数学模型
这是“未知参数 + 两点边值约束”的问题，可改写为一阶系统并把 `mu` 作为待估参数：

- 设 `z1=y, z2=y'`
- 则
  - `z1' = z2`
  - `z2' = -mu*z1`

边界条件写成：

- `z1(0)=0`
- `z2(0)=1`
- `z1(1)+z2(1)=0`

未知量为函数 `z1,z2` 与参数 `mu`，共 3 个边界约束，方程配套完整。

## 解析关系（用于校验）
若 `mu>0`，令 `k=sqrt(mu)`，由 `y(0)=0, y'(0)=1` 得：

- `y(x)=sin(kx)/k`

代入末端边界 `y(1)+y'(1)=0`：

- `sin(k)/k + cos(k) = 0`
- `tan(k) = -k`

故 `k` 为方程 `tan(k)+k=0` 的根，`mu=k^2`。  
该方程有无穷多个根，对应多阶模态；通常取最小正根作为第一模态。

## 数值求解方法
- 用 `scipy.integrate.solve_bvp` 直接解“函数+参数”的边值问题；
- 用 `scipy.optimize.root_scalar` 求 `tan(k)+k=0` 的同阶根，作为校验。

## 结果与校验
- 输出 `mu` 数值解（BVP）；
- 输出解析校验值（由 `tan(k)+k=0` 得到）及两者差异；
- 输出边界残差；
- 绘制 `y(x)` 曲线。
