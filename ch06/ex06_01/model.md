# 例题 6.1 模型（牛顿冷却定律）

## 题意重述
将某物体放置于空气中，设空气温度恒定为 `20°C`。已知：

- `t=0` 时物体温度 `u(0)=100°C`；
- `t=20 min` 时物体温度 `u(20)=60°C`。

要求：
1. 建立物体温度 `u` 与时间 `t` 的关系；
2. 计算物体达到 `30°C` 所需时间。

## 已知数据与符号说明
- `u(t)`：时刻 `t` 的物体温度（°C）
- `u_a`：环境温度（°C），本题 `u_a=20`
- `k`：冷却系数（`min^-1`），`k>0`

## 数学模型
根据牛顿冷却定律：

- `du/dt = -k * (u - u_a)`

代入 `u_a=20`：

- `du/dt = -k * (u - 20)`

这是一阶线性常微分方程，其通解为：

- `u(t) = 20 + C * exp(-k t)`

由初值 `u(0)=100` 得 `C=80`，即：

- `u(t) = 20 + 80 * exp(-k t)`

再由 `u(20)=60`：

- `60 = 20 + 80*exp(-20k)`
- `exp(-20k)=1/2`
- `k = ln(2)/20`

故解析式：

- `u(t) = 20 + 80*exp(-(ln2/20)t) = 20 + 80*2^(-t/20)`

## 目标时刻计算
令 `u(t)=30`：

- `30 = 20 + 80*2^(-t/20)`
- `2^(-t/20)=1/8=2^-3`
- `t=60 min`

即：
- 从 `t=0` 起约 `60 min` 达到 `30°C`；
- 若从第二次测量时刻 `t=20 min` 起算，还需 `40 min`。

## 方法选择与理由
- 本题有标准解析解，直接用微分方程解析推导最简洁；
- 代码中使用 `sympy` 做符号求解与代数校验，避免手算出错。
