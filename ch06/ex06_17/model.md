# 例题 6.17 模型（非线性微分方程组边值问题）

## 题意重述
求解方程组：

- `u' = 0.5*u*(w-u)/v`
- `v' = -0.5*(w-u)`
- `w' = (0.9 - 1000*(w-y) - 0.5*w*(w-u))/z`
- `z' = 0.5*(w-u)`
- `y' = -100*(y-w)`

边界条件：

- `u(0)=1`
- `v(0)=1`
- `w(0)=1`
- `z(0)=-10`
- `w(1)=y(1)`

## 已知数据与符号说明
- 独立变量：`t ∈ [0,1]`
- 状态变量：`u(t), v(t), w(t), z(t), y(t)`
- 这是一个 5 维非线性边值问题（BVP），其中 4 个条件在 `t=0`，1 个条件在 `t=1`。

## 数学模型
写成向量形式：

- `X' = F(t, X)`
- `X=[u,v,w,z,y]^T`

边界条件向量 `B(X(0),X(1))=0`：

- `u(0)-1=0`
- `v(0)-1=0`
- `w(0)-1=0`
- `z(0)+10=0`
- `w(1)-y(1)=0`

## 数值求解方法
- 使用 `scipy.integrate.solve_bvp` 直接求解非线性 BVP；
- 在初始猜测中令 `u,v,w≈1`、`z≈-10`、`y≈1` 并加入轻微扰动，帮助收敛；
- 对求解结果输出边界残差和方程残差近似量级。

## 结果与校验
- 输出收敛状态、迭代次数、网格节点数；
- 输出关键边界值（`u(0),v(0),w(0),z(0),w(1),y(1)`）；
- 输出边界残差 `max|B_i|`；
- 绘制 `u,v,w,z,y` 随 `t` 的曲线。
