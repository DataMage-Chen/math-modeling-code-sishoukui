# 例题 6.12 模型（平面追击问题）

## 题意重述
慢跑者在平面上的轨迹为：

- `X(t)=10+20cos t`
- `Y(t)=20+15sin t`

一只狗从原点 `(0,0)` 出发，以恒定速率 `w` 追击慢跑者，且狗在任意时刻的速度方向始终指向慢跑者当前位置。  
要求分别求 `w=20` 与 `w=5` 时狗的运动轨迹。

## 已知数据与符号说明
- 慢跑者位置：`R(t)=[X(t),Y(t)]^T`
- 狗的位置：`D(t)=[x(t),y(t)]^T`
- 狗速率：`|D'(t)|=w`（常数）
- 初值：`D(0)=(0,0)`
- 相对向量：`r(t)=R(t)-D(t)`
- 距离：`d(t)=||r(t)||`

## 数学模型
由于“方向始终指向慢跑者”，狗的速度向量为：

- `D'(t)=w * r(t)/||r(t)||`

分量形式：

- `dx/dt = w*(X(t)-x)/sqrt((X(t)-x)^2+(Y(t)-y)^2)`
- `dy/dt = w*(Y(t)-y)/sqrt((X(t)-x)^2+(Y(t)-y)^2)`

其中：

- `X(t)=10+20cos t`
- `Y(t)=20+15sin t`

这是带时变驱动项的二维非线性常微分方程初值问题。

## 数值求解方法
- 使用 `scipy.integrate.solve_ivp` 对上式积分；
- 分别代入 `w=20` 与 `w=5`；
- 可设置“捕获事件”：
  - 当 `d(t) <= tol`（例如 `tol=1e-2`）认为狗追上慢跑者；
  - 事件触发后终止积分并记录捕获时间与捕获点。

## 结果与校验
- 输出每个 `w` 对应的：
  - 是否在给定时间窗内追上；
  - 追上时刻（若追上）；
  - 最小距离（若未追上）。
- 绘制轨迹图：
  - 慢跑者轨迹；
  - 狗轨迹（`w=20`、`w=5`）；
  - 起点与捕获点标记（如有）。
