# 例题 6.5 模型（四阶线性常系数微分方程）

## 题意重述
已知输入信号：

- `u(t)=e^{-t} cos t`

求解初值问题：

- `y^{(4)} + 10y^{(3)} + 35y'' + 50y' + 24y = u''(t)`
- `y(0)=0, y'(0)=-1, y''(0)=1, y'''(0)=1`

## 已知数据与符号说明
- 自变量：`t`
- 未知函数：`y(t)`
- 输入：`u(t)=e^{-t} cos t`
- 右端：`u''(t)=2e^{-t} sin t`

## 数学模型
这是四阶线性常系数非齐次 ODE。

### 1) 齐次解
对应特征方程：

- `r^4+10r^3+35r^2+50r+24=0`
- 分解为 `(r+1)(r+2)(r+3)(r+4)=0`

故齐次解：

- `y_h = C1 e^{-t} + C2 e^{-2t} + C3 e^{-3t} + C4 e^{-4t}`

### 2) 特解
右端 `2e^{-t}sin t`，设特解：

- `y_p = e^{-t}(A cos t + B sin t)`

代入可得 `A=0, B=-1/5`，即：

- `y_p = -(1/5)e^{-t}sin t`

### 3) 通解与初值
通解：

- `y = y_h + y_p`

代入四个初值解得常数：

- `C1=-7/3, C2=9/2, C3=-14/5, C4=19/30`

故解析解：

- `y(t)= -7/3 e^{-t} + 9/2 e^{-2t} - 14/5 e^{-3t} + 19/30 e^{-4t} - 1/5 e^{-t} sin t`

## 结果与校验
- 校验 1：`y(0),y'(0),y''(0),y'''(0)` 满足给定初值；
- 校验 2：代回方程残差为 0；
- 代码中再用 `sympy.dsolve` 做符号求解，对比手工表达式与符号解等价性。
