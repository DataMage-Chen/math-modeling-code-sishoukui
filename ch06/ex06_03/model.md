# 例题 6.3 模型（一阶线性微分方程）

## 题意重述
求解初值问题：

- `y' = -2y + 2x^2 + 2x`
- `y(0)=1`

## 已知数据与符号说明
- 自变量：`x`
- 待求函数：`y(x)`
- 初值：`x=0` 时 `y=1`

## 数学模型
将方程写为标准线性形式：

- `y' + 2y = 2x^2 + 2x`

### 方法一：待定系数法（快速）
先设一个二次多项式特解：

- `y_p = ax^2 + bx + c`

代回方程可得：

- `a=1, b=0, c=0`

所以 `y_p = x^2`。对应齐次方程 `y_h' + 2y_h=0` 的解为：

- `y_h = C e^{-2x}`

通解：

- `y = x^2 + C e^{-2x}`

由初值 `y(0)=1` 得 `C=1`，故解析解为：

- `y(x)=x^2 + e^{-2x}`

### 方法二：积分因子法（等价）
积分因子 `mu(x)=e^{2x}`，同样可得到上述解。

## 结果与校验
- 解析解：`y(x)=x^2 + e^{-2x}`
- 校验：
  - 初值：`y(0)=1`
  - 代回：`y' + 2y - (2x^2+2x)=0`
