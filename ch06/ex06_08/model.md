# 例题 6.8 模型（常微分方程组，混合初边值条件）

## 题意重述
求解方程组

- `f'' + g = 3`
- `g' + f' = 1`

在条件

- `f'(1)=0`
- `f(0)=0`
- `g(0)=0`

下的解。

## 已知数据与符号说明
- 自变量：`t`（也可记作 `x`）
- 未知函数：`f(t), g(t)`
- 条件类型：`t=0` 给出函数值，`t=1` 给出导数值（混合初边值条件）

## 数学模型与求解
由第二式：

- `g' + f' = 1`
- `(g+f)' = 1`
- `g + f = t + C`

由 `f(0)=0, g(0)=0` 得 `C=0`，故：

- `g = t - f`

代回第一式：

- `f'' + (t-f) = 3`
- `f'' - f = 3 - t`

得到一元二阶线性方程。

### 1) 求 `f`
齐次解：

- `f_h = C1 e^t + C2 e^{-t}`

对右端 `3-t` 取特解 `f_p = a t + b`，代回得 `a=1,b=-3`，故：

- `f = C1 e^t + C2 e^{-t} + t - 3`

### 2) 求 `g`
由 `g=t-f`：

- `g = 3 - C1 e^t - C2 e^{-t}`

### 3) 用条件确定常数
由 `f(0)=0`：

- `C1 + C2 = 3`

由 `f'(t)=C1 e^t - C2 e^{-t} + 1`，再用 `f'(1)=0`：

- `C1 e - C2/e + 1 = 0`

解得：

- `C1 = (3-e)/(e^2+1)`
- `C2 = e(3e+1)/(e^2+1)`

并可验算 `g(0)=0` 自动满足。

## 解析解
- `f(t)= ((3-e)/(e^2+1)) e^t + (e(3e+1)/(e^2+1)) e^{-t} + t - 3`
- `g(t)= 3 - ((3-e)/(e^2+1)) e^t - (e(3e+1)/(e^2+1)) e^{-t}`

## 结果与校验
- 校验方程残差：
  - `f''+g-3=0`
  - `g'+f'-1=0`
- 校验条件：
  - `f(0)=0`
  - `g(0)=0`
  - `f'(1)=0`
