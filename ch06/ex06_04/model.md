# 例题 6.4 模型（二阶线性常系数微分方程）

## 题意重述
求解初值问题：

- `y'' - 2y' + y = e^x`
- `y(0)=1, y'(0)=-1`

## 已知数据与符号说明
- 自变量：`x`
- 未知函数：`y(x)`
- 初值：`y(0)=1, y'(0)=-1`

## 数学模型
这是二阶线性非齐次常微分方程。

### 1) 齐次解
对应齐次方程：

- `y'' - 2y' + y = 0`

特征方程：

- `r^2 - 2r + 1 = (r-1)^2 = 0`

故齐次解：

- `y_h = (C1 + C2 x)e^x`

### 2) 特解
右端为 `e^x`，与重根 `r=1` 重合且重数为 2，设特解：

- `y_p = A x^2 e^x`

代回可得：

- `2A e^x = e^x  =>  A=1/2`

故：

- `y_p = (1/2) x^2 e^x`

### 3) 通解与初值
通解：

- `y = e^x (C1 + C2 x + x^2/2)`

由 `y(0)=1` 得 `C1=1`。  
求导：

- `y' = e^x(C1 + C2 x + x^2/2) + e^x(C2 + x)`
- `y'(0)=C1 + C2 = -1`

代入 `C1=1` 得 `C2=-2`。

故解析解：

- `y(x) = e^x(1 - 2x + x^2/2)`

## 结果与校验
- 解析解：`y(x)=e^x(1-2x+x^2/2)`
- 校验：
  - 初值 `y(0)=1, y'(0)=-1`
  - 代回原方程残差为 0
