# 例题 6.9 模型（续例 6.3：数值解与符号解对比）

## 题意重述
对初值问题

- `y' = -2y + 2x^2 + 2x`
- `y(0)=1`
- `0 <= x <= 0.5`

求其数值解，并在同一图中画出数值解曲线与符号解（解析解）曲线。

## 已知数据与符号说明
- 自变量：`x`
- 未知函数：`y(x)`
- 初值：`y(0)=1`
- 右端函数：`f(x,y) = -2y + 2x^2 + 2x`

## 数学模型
### 1) 常微分方程初值问题

- `dy/dx = f(x,y), y(0)=1`

### 2) 符号解（解析解）
由例 6.3 可得：

- `y_exact(x) = x^2 + e^{-2x}`

### 3) 数值解
使用 `solve_ivp`（Runge-Kutta 类方法）在区间 `[0,0.5]` 上积分，得到 `y_num(x)`。

## 对比与误差
在同一网格点上比较：

- `e(x) = y_num(x) - y_exact(x)`

输出指标：

- 最大绝对误差 `max|e|`
- RMSE `sqrt(mean(e^2))`

并在同一图中绘制 `y_num(x)` 与 `y_exact(x)` 进行可视化对比。

## 方法选择与理由
- `solve_ivp` 是 SciPy 中常用且稳定的 ODE 初值问题求解器；
- 解析解已知，适合用于验证数值算法精度与参数设置（`rtol/atol`）。
