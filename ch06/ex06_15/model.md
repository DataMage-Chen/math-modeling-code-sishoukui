# 例题 6.15 模型（小水滴横截面边值问题）

## 题意重述
求解并绘制函数 `h(x)`，其满足边值问题：

- `h''(x) + (1-h(x)) * (1 + (h'(x))^2)^(3/2) = 0`
- `h(-1)=0, h(1)=0`

## 已知数据与符号说明
- 自变量：`x ∈ [-1,1]`
- 未知函数：`h(x)`（水滴横截面高度）

## 数学模型
将二阶非线性方程化为一阶系统，令：

- `y1 = h`
- `y2 = h'`

则：

- `y1' = y2`
- `y2' = -(1-y1)*(1+y2^2)^(3/2)`

边界条件变为：

- `y1(-1)=0`
- `y1(1)=0`

这是一个非线性两点边值问题（BVP）。

## 数值求解方法
- 使用 `scipy.integrate.solve_bvp` 求解上述一阶系统；
- 初值猜测取对称抛物线（如 `h0(x)=a(1-x^2)`）以提高收敛稳定性；
- 收敛后在致密网格上评估 `h(x)` 并绘图。

## 结果与校验
- 输出求解器收敛状态与迭代信息；
- 输出 `h(x)` 的最大值及对应位置；
- 检查边界条件误差 `|h(-1)|, |h(1)|`；
- 绘制 `h(x)` 曲线。
