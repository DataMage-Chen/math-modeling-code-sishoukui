# 例题 6.20 模型（捕食者-被捕食者系统的周期与极值）

## 题意重述
给定捕食者-被捕食者方程组：

- `dx/dt = 0.2x - 0.005xy, x(0)=70`
- `dy/dt = -0.5y + 0.01xy, y(0)=40`

其中：
- `x(t)`：`t` 个月后的兔子总数量；
- `y(t)`：`t` 个月后的狐狸总数量。

要求研究：
1. `x(t), y(t)` 总数量变化的周期；
2. `x(t)` 的最大值和最小值；
3. `y(t)` 的最大值和最小值。

## 已知数据与符号说明
- 参数：`a=0.2, b=0.005, c=0.5, d=0.01`
- 初值：`x(0)=70, y(0)=40`
- 平衡点：`(x*,y*)=(c/d,a/b)=(50,40)`

## 数学模型
这是经典 Lotka-Volterra 系统：

- `dx/dt = a x - b x y`
- `dy/dt = -c y + d x y`

为获得周期与极值，采用数值积分得到长时间轨线：

- 在 `t ∈ [0,T]` 上求 `x(t), y(t)`；
- 通过局部峰值/谷值时刻估计周期与振幅。

## 数值计算步骤
1. 使用 `solve_ivp` 积分方程组；
2. 在致密时间网格上提取 `x(t), y(t)`；
3. 寻找局部极大值和极小值：
   - 由相邻点比较判定峰/谷；
4. 周期估计：
   - 取同一变量相邻峰值时刻差 `Δt`；
   - 用 `mean(Δt)` 作为该变量周期估计；
5. 极值估计：
   - 用峰值平均近似最大值；
   - 用谷值平均近似最小值。

## 结果与校验
- 输出 `x(t)` 与 `y(t)` 的周期估计；
- 输出 `x_max, x_min, y_max, y_min`；
- 绘制：
  - 时间序列图（`x(t), y(t)`）；
  - 相图（`x-y` 轨迹）；
- 可检查不同积分精度/时长下结果稳定性。
