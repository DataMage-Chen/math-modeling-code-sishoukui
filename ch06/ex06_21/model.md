# 例题 6.21 模型（圆桶下沉速度安全性分析）

## 题意重述
将装有放射性废料的密封圆桶沉入海底（深约 90m），需判断入海方案是否安全。  
已知：

- 圆桶质量 `m = 239.46 kg`
- 圆桶体积 `V = 0.2058 m^3`
- 海水密度 `rho = 1035.71 kg/m^3`
- 裂桶风险阈值速度 `v_safe = 12.2 m/s`
- 阻力系数 `k = 0.6`

要求：
1. 判断该处理方法是否合理（海底撞击速度是否超过 `12.2 m/s`）；
2. 当速度较大时将线性阻力参数替换为 `k v`（即二次阻力模型），求速度-时间关系，并给出“速度不超过 `12.2 m/s` 时”对应运动时间与位移上限。

## 已知数据与符号说明
- 取竖直向下为正方向；
- `v(t)`：下沉速度；
- `s(t)`：下沉位移，`s(0)=0`；
- 重力：`G = m g`；
- 浮力：`B = rho g V`；
- 有效下拉常量：`F0 = G - B = (m-rho V)g`。

## 数学模型
### 1) 线性阻力模型（题设基础）
阻力与速度成正比：`R = k v`。  
动力学方程：

- `m dv/dt = F0 - k v`

解为：

- `v(t) = v_inf * (1 - exp(-k t/m))`
- `v_inf = F0/k`

位移：

- `s(t) = ∫_0^t v(tau) d tau`
- `s(t) = v_inf * [ t - (1 - exp(-k t/m)) / (k/m) ]`

用 `s(t)=90` 求海底撞击时刻 `t_90`，进而得到撞击速度 `v(t_90)`，并与 `12.2 m/s` 比较。

### 2) 高速时二次阻力模型（将 `k` 替换为 `k v`）
此时阻力为 `R = k v^2`，方程变为：

- `m dv/dt = F0 - k v^2`

令

- `v_t = sqrt(F0/k)`
- `alpha = sqrt(F0*k)/m`

则速度-时间关系：

- `v(t) = v_t * tanh(alpha t)`

位移：

- `s(t) = (m/k) * ln(cosh(alpha t))`

当要求 `v(t) <= v_safe` 时：

- `t <= t_safe = atanh(v_safe/v_t)/alpha`（前提 `v_safe < v_t`）
- `s <= s_safe = (m/k) ln(cosh(alpha t_safe))`

## 结果与校验
- 输出线性模型下海底撞击速度，判断是否安全；
- 输出二次阻力模型下 `v(t)` 解析式及 `t_safe, s_safe`；
- 输出在 90m 深度对应速度（可线性与二次模型对照）；
- （可选）绘制 `v-t` 与 `s-t` 曲线并标注 `v_safe`、`s=90m`。
