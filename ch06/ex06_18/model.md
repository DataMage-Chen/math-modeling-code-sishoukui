# 例题 6.18 模型（Logistic 人口预测模型）

## 题意重述
利用表 6.1 给出的美国人口统计数据（单位：百万），建立人口预测模型，并据此预测 2010 年美国人口。

数据（年份-人口，单位：百万）：

- 1790: 3.9, 1800: 5.3, 1810: 7.2, 1820: 9.6, 1830: 12.9, 1840: 17.1, 1850: 23.2, 1860: 31.4
- 1870: 38.6, 1880: 50.2, 1890: 62.9, 1900: 76.0, 1910: 92.0, 1920: 106.5, 1930: 123.2, 1940: 131.7
- 1950: 150.7, 1960: 179.3, 1970: 204.0, 1980: 226.5, 1990: 251.4, 2000: 281.4

## 已知数据与符号说明
- `P(t)`：人口（百万）
- 时间基准：`t = year - 1790`
- `K`：环境容量（极限人口规模）
- `r`：内禀增长率

## 数学模型
采用 Logistic 微分方程：

- `dP/dt = r*P*(1 - P/K)`

解析解可写为：

- `P(t) = K / (1 + b*exp(-r*t))`

若固定初值 `P(0)=P0`，则：

- `b = (K-P0)/P0`

本题默认采用“固定 `P0=3.9`（1790 年数据）”的两参数拟合形式：

- `P(t)= K / (1 + ((K-P0)/P0)*exp(-r*t))`

## 参数估计
利用最小二乘法拟合 `K,r`：

- `min Σ_i (P_model(t_i;K,r)-P_i)^2`

其中 `t_i = year_i - 1790`，`P_i` 为表中人口观测值。

## 预测
2010 年对应：

- `t_2010 = 2010 - 1790 = 220`

代入拟合模型得到预测值：

- `P_2010 = P(t_2010)`

## 结果与校验
- 输出拟合参数 `K,r`（及隐含参数 `b`）；
- 输出拟合误差指标：SSE、RMSE、`R^2`；
- 输出 2010 年预测值；
- 绘制观测点、Logistic 拟合曲线及 2010 预测点。
