# 习题 6.4 模型（竖直加热板自然对流）

## 题意重述
求下列非线性微分方程组在区间 \([0,10]\) 上的数值解，并绘制 \(f(\eta)\)、\(T(\eta)\) 曲线：

\[
\begin{cases}
\dfrac{d^3 f}{d\eta^3} + 3f\dfrac{d^2 f}{d\eta^2} - 2\left(\dfrac{df}{d\eta}\right)^2 + T = 0,\\
\dfrac{d^2 T}{d\eta^2} + 2.1 f\dfrac{dT}{d\eta} = 0.
\end{cases}
\]

初值条件（\(\eta=0\)）：

\[
f(0)=0,\quad f'(0)=0,\quad f''(0)=0.68,\quad T(0)=1,\quad T'(0)=-0.5.
\]

## 数学模型改写
为使用标准数值 ODE 求解器，将高阶方程改写为一阶系统：

\[
y_1=f,\quad y_2=f',\quad y_3=f'',\quad y_4=T,\quad y_5=T',
\]

\[
\begin{cases}
y_1' = y_2,\\
y_2' = y_3,\\
y_3' = -3y_1y_3 + 2y_2^2 - y_4,\\
y_4' = y_5,\\
y_5' = -2.1y_1y_5.
\end{cases}
\]

对应初值：
\[
y_1(0)=0,\ y_2(0)=0,\ y_3(0)=0.68,\ y_4(0)=1,\ y_5(0)=-0.5.
\]

## 求解方法
- 本题是初值问题（IVP），采用 `scipy.integrate.solve_ivp` 数值积分；
- 默认在 \([0,10]\) 上用 `RK45` 求解，也支持命令行切换积分方法；
- 输出末端状态、变量范围，以及求解器统计信息（如函数调用次数）。
