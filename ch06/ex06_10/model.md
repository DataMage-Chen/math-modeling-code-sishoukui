# 例题 6.10 模型（奇点附近的二阶非线性微分方程数值解）

## 题意重述
用数值法求解初值问题：

- `(1-x) * y'' = (1/5) * sqrt(1 + (y')^2), 0 < x <= 1`
- `y(0)=0, y'(0)=0`

## 已知数据与符号说明
- 自变量：`x`
- 未知函数：`y(x)`
- 辅助变量：`p(x)=y'(x)`

## 数学模型
将二阶方程改写为一阶系统：

- `y' = p`
- `p' = sqrt(1+p^2) / (5*(1-x))`

初值：

- `y(0)=0`
- `p(0)=0`

## 数值求解要点
### 1) 端点奇性处理
方程在 `x=1` 处存在分母 `1-x`，右端奇异，因此数值积分不直接取到 `x=1`，而是积分到：

- `x_end = 1 - eps`

其中 `eps` 取很小正数（如 `1e-6` 或 `1e-8`）。

### 2) 求解器选择
采用 `scipy.integrate.solve_ivp`（如 `RK45` / `DOP853`）进行初值积分，并设置较严格容差（`rtol/atol`）控制误差。

### 3) 结果输出
- 输出 `x_end` 处的 `y(x_end)` 与 `y'(x_end)`；
- 绘制 `y(x)`、`y'(x)` 数值曲线；
- （可选）与参考解析式对比误差。

## 说明
- 该题虽然可推得解析表达，但本例强调“数值法求解”；
- 在靠近 `x=1` 的区间，`y'(x)` 增长较快，建议适当加密网格并减小容差。
