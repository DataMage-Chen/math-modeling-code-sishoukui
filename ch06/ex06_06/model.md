# 例题 6.6 模型（线性常系数微分方程组的柯西问题）

## 题意重述
求解柯西问题：

- `dx/dt = A x`
- `x(0) = [1,1,1]^T`

其中

- `x(t) = [x1(t), x2(t), x3(t)]^T`
- `A = [[3,-1,1],[2,0,-1],[1,-1,2]]`

## 已知数据与符号说明
- `A`：常系数矩阵
- `x(t)`：状态向量
- 初值向量：`x0=[1,1,1]^T`

## 数学模型
线性系统的通解可写成：

- `x(t) = exp(A t) x0`

也可通过特征分解求解。先求 `A` 的特征值与特征向量：

- 特征多项式：`det(A-lambda I) = -lambda(lambda-2)(lambda-3)`
- 特征值：`lambda1=0, lambda2=2, lambda3=3`
- 对应一组特征向量可取：
  - `v1=[1,5,2]^T`（对应 `lambda=0`）
  - `v2=[1,1,0]^T`（对应 `lambda=2`）
  - `v3=[2,1,1]^T`（对应 `lambda=3`）

故通解：

- `x(t)=c1*v1 + c2*e^{2t}*v2 + c3*e^{3t}*v3`

由初值 `x(0)=x0` 求得：

- `c1=1/6, c2=-1/2, c3=2/3`

从而得到解析解：

- `x1(t)=1/6 - (1/2)e^{2t} + (4/3)e^{3t}`
- `x2(t)=5/6 - (1/2)e^{2t} + (2/3)e^{3t}`
- `x3(t)=1/3 + (2/3)e^{3t}`

## 结果与校验
- 校验初值：`x(0)=[1,1,1]^T`
- 校验方程：`dx/dt - A x = 0`
- 代码中同时用 `exp(A t)x0` 和分量解析式互相核对，确保一致。
