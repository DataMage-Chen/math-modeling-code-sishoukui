# 例题 6.11 模型（Lorenz 系统的混沌效应复现）

## 题意重述
复现 Lorenz 模型在参数

- `sigma = 10`
- `rho = 28`
- `beta = 8/3`

下的典型混沌现象：

1. 绘制三维相轨线（蝴蝶吸引子）；
2. 取两组极其接近的初值（相差 `10^-4`），比较解随时间的偏差演化，展示对初值的敏感性。

## 已知数据与符号说明
Lorenz 方程组：

- `dx/dt = sigma*(y-x)`
- `dy/dt = rho*x - y - x*z`
- `dz/dt = x*y - beta*z`

状态向量：`X(t)=[x(t),y(t),z(t)]^T`。  
参数含义：`sigma` 为 Prandtl 数，`rho` 为 Rayleigh 数，`beta` 为几何比参数。

## 数学模型
### 1) 主轨线仿真
在区间 `[0,T]` 上，对 Lorenz 系统做数值积分，得到 `X(t)`，并在三维空间绘制 `(x,y,z)`。

### 2) 初值敏感性实验
设两组初值：

- `X0`
- `X0^* = X0 + [delta,delta,delta]^T`

其中 `delta=10^-4`。  
对两组初值分别积分，得到 `X(t)` 与 `X^*(t)`，考察偏差：

- `Delta_x(t) = x(t)-x^*(t)`
- （可选）`||Delta(t)||_2 = ||X(t)-X^*(t)||_2`

若系统处于混沌状态，极小初值差会随时间放大。

## 方法选择与理由
- 使用 `scipy.integrate.solve_ivp`（如 `RK45`）求解非线性常微分方程组；
- 用固定 `t_eval` 保证两条轨线在同一时刻网格上可直接比较；
- 用三维轨线图 + 分量差值图直观复现教材图像风格。

## 结果与校验
- 输出参数、初值、扰动量；
- 绘制 3D 轨线（蝴蝶吸引子）；
- 绘制 `Delta_x(t)`（以及可选范数）；
- 输出末时刻偏差与最大偏差，验证“初值敏感性”。

## Lorenz 系统的物理含义（简述）
- Lorenz 系统源于对“大气热对流”方程的低维截断近似，是一个三维确定性非线性动力系统；
- 三个状态变量常解释为：
  - `x`：对流环流强度（速度幅度）；
  - `y`：水平温差驱动量；
  - `z`：垂向温度分布偏离量；
- 参数意义：
  - `sigma`：Prandtl 数（动量扩散与热扩散相对强度）；
  - `rho`：受热强度参数（与 Rayleigh 数相关）；
  - `beta`：几何/耗散参数；
- 在经典参数 `sigma=10, rho=28, beta=8/3` 下，系统虽是确定性的，却表现出混沌与“初值敏感性”（蝴蝶效应）：
  - 初值极小差异会随时间显著放大；
  - 这解释了类似天气系统“短期可预报、长期难精确预报”的现象。
