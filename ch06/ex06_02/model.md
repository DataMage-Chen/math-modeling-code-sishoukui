# 例题 6.2 模型（目标跟踪/追击曲线）

## 题意重述
甲舰在原点 `O(0,0)` 发射导弹，目标乙舰初始在 `Q0(1,0)`。导弹始终瞄准乙舰（速度方向始终指向乙舰当前位置）。  
若乙舰以常速 `v0` 沿平行 `y` 轴直线 `x=1` 行驶，导弹速度恒为 `5v0`，求：

1. 导弹轨迹方程；
2. 乙舰被击中前行驶的距离。

## 已知数据与符号说明
- 导弹位置：`P(x,y)`
- 乙舰位置：`Q(1,s)`，其中 `s=v0 t`
- 速度比：`|v_m|:|v_t| = 5v0:v0 = 5:1`
- 初值：`P(0)=(0,0)`，`Q(0)=(1,0)`

## 几何关系与微分方程
### 1) 瞄准条件（切线方向）
导弹速度方向与连线 `PQ` 一致，故导弹轨迹切线斜率满足：

- `dy/dx = (s-y)/(1-x) = p`

即 `p` 可看作“视线斜率”。

### 2) 速度比条件
由几何可得导弹在 `x` 方向速度：

- `dx/dt = 5v0 / sqrt(1+p^2)`

又 `ds/dt=v0`，因此：

- `ds/dx = (ds/dt)/(dx/dt) = sqrt(1+p^2)/5`

另一方面由 `s = y + p(1-x)` 对 `x` 求导，得到：

- `ds/dx = (1-x) dp/dx`

联立可得一阶方程：

- `(1-x) dp/dx = sqrt(1+p^2)/5`
- `p(0)=0`

积分得：

- `arsinh(p) = -(1/5) ln(1-x)`
- `p(x)=dy/dx = ( (1-x)^(-1/5) - (1-x)^(1/5) ) / 2`

再积分并用 `y(0)=0`：

- `y(x) = 5/24 - (5/8)(1-x)^(4/5) + (5/12)(1-x)^(6/5), 0<=x<=1`

这就是导弹追击曲线。

## 被击中时刻与乙舰行程
击中时两者重合，必有 `x -> 1`。代入轨迹式：

- `y_hit = y(1) = 5/24`

而乙舰沿 `x=1` 竖直航行，所以其行驶距离就是 `s_hit=y_hit`：

- `L = 5/24`（坐标长度单位）

若写成时间：

- `t_hit = L / v0 = 5/(24v0)`

## 说明
- 结果 `L=5/24` 是在初始横向间距为 `1` 的归一化坐标下得到。  
  若初始间距为 `D`，则结论按尺度放大为 `L=(5/24)D`。
