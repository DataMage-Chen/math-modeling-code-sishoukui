# 例题 6.19 模型（捕食者-被捕食者参数辨识）

## 题意重述
已知捕食者-被捕食者模型：

- `dx/dt = a*x - b*x*y,  x(0)=60`
- `dy/dt = -c*y + d*x*y, y(0)=30`

其中：
- `x(t)`：兔子数量；
- `y(t)`：狐狸数量；
- `a,b,c,d`：待辨识参数。

利用表 6.2 的 13 组观测值（`t,x(t),y(t)`）拟合参数 `a,b,c,d`。

## 观测数据
- 时间（月）：`[0,1,2,3,4,5,6,8,10,12,14,16,18]`
- 兔子：`[60,63,64,63,61,58,53,44,39,38,41,46,53]`
- 狐狸：`[30,34,38,44,50,55,58,56,47,38,30,27,26]`

## 数学模型
定义参数向量：

- `theta = [a,b,c,d]^T`

给定 `theta` 后，通过数值积分得到模型解：

- `x_model(t_i;theta), y_model(t_i;theta)`

然后构造最小二乘目标：

- `min_theta  Σ_i ((x_model(t_i)-x_i)/sx)^2 + Σ_i ((y_model(t_i)-y_i)/sy)^2`

其中 `sx, sy` 为尺度因子（如样本标准差），用于平衡两类观测量级。

## 数值求解方法
1. 对每组参数 `theta` 用 `solve_ivp` 在观测时刻积分；
2. 用 `least_squares` 最小化残差向量；
3. 为降低局部极值影响，采用多初值（multi-start）并取最优解；
4. 参数约束 `a,b,c,d > 0`（在实现中用对数参数化或正区间约束）。

## 结果与校验
- 输出拟合参数 `a,b,c,d`；
- 输出拟合误差指标（SSE、RMSE、`R^2`）；
- 输出观测值与拟合值对照表；
- 绘制：
  - 时间序列拟合图（兔子/狐狸）；
  - 相图（`x-y` 轨迹）对比。
