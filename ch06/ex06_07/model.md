# 例题 6.7 模型（线性系统初值问题）

## 题意重述
求解初值问题：

- `x'(t) = A x(t) + b(t)`
- `x(0) = [0,1,1]^T`

其中

- `x(t)=[x1(t),x2(t),x3(t)]^T`
- `A=[[1,0,0],[2,1,-2],[3,2,1]]`
- `b(t)=[0,0,e^t cos(2t)]^T`

## 数学模型
方程展开为：

- `x1' = x1`
- `x2' = 2x1 + x2 - 2x3`
- `x3' = 3x1 + 2x2 + x3 + e^t cos(2t)`

### 1) 先解 `x1`
由 `x1' = x1, x1(0)=0` 得：

- `x1(t)=0`

于是后两式变为：

- `x2' = x2 - 2x3`
- `x3' = 2x2 + x3 + e^t cos(2t)`

### 2) 消元得到 `x2` 的二阶方程
由 `x3=(x2-x2')/2`，代入可得：

- `x2'' - 2x2' + 5x2 = -2e^t cos(2t)`
- `x2(0)=1`
- `x2'(0)=x2(0)-2x3(0)= -1`

令 `x2=e^t z`，可化为：

- `z'' + 4z = -2 cos(2t)`

解得：

- `z = cos(2t) - sin(2t) - (1/2)t sin(2t)`

故：

- `x2(t)=e^t[cos(2t)-sin(2t)-(1/2)t sin(2t)]`

### 3) 回代求 `x3`
由 `x3=(x2-x2')/2` 得：

- `x3(t)=e^t[(2+t)/2 * cos(2t) + 5/4 * sin(2t)]`

同时 `x3(0)=1` 自动满足。

## 解析解
最终：

- `x1(t)=0`
- `x2(t)=e^t[cos(2t)-sin(2t)-(1/2)t sin(2t)]`
- `x3(t)=e^t[(2+t)/2*cos(2t)+5/4*sin(2t)]`

## 结果与校验
- 校验初值：`x(0)=[0,1,1]^T`
- 校验残差：`x'(t)-A x(t)-b(t)=0`
