# 习题 5.9 模型（水箱流量反演）

## 题意重述
已知某供水系统在若干时刻的水箱水位数据（表 5.18），部分时段标记为“泵水”。在仅有水位观测的情况下，估计任意时刻（包括泵水期间）从水箱流出的流量 `f(t)`。

已知：
- 长度单位 `E`，`1E=30.24cm`；
- 水箱为圆柱体，直径 `57E`；
- 表中水位单位为 `10^-2 E`。

假设：
1. 影响流出量的唯一因素是公众用水需求；
2. 水泵灌水速度为常数；
3. 最大流出速度小于水泵灌水速度；
4. 每天用水分布相似；
5. 流量变化可由光滑曲线近似。

## 已知数据与符号说明
- `h(t)`：水位高度（m）
- `A`：水箱横截面积（m²），`A = pi*(D/2)^2`
- `D = 57E`
- `q_p`：泵水流量（常数，m³/s）
- `u(t)`：泵开关函数（泵开=1，泵关=0）
- `f(t)`：待求流出流量（m³/s）

质量守恒（体积守恒）：

- `A * dh/dt = u(t)*q_p - f(t)`

### 如何由水位反推流量（核心思路）
1. **单位换算与几何换算**  
   - 水位原始单位是 `10^-2 E`，先换成米：`h(m)=h_raw*10^-2*0.3024`；  
   - 水箱为圆柱体，`D=57E=57*0.3024(m)`，`A=pi*(D/2)^2`。  
   这样 `A*dh/dt` 的单位就是 `m^3/s`，可直接对应流量。

2. **由水位斜率得到“净流量”**  
   - 任意时刻有：`A*dh/dt = q_in(t)-f(t)`，其中 `q_in(t)=u(t)*q_p`；  
   - 因此 `A*dh/dt` 实际上是“入流-出流”的净效应：  
     - 若泵关（`u=0`），则 `f(t) = -A*dh/dt`；  
     - 若泵开（`u=1`），则 `f(t) = q_p - A*dh/dt`。

3. **离散观测下的近似解释**  
   对相邻观测点 `(t_i,h_i),(t_{i+1},h_{i+1})`，可写平均斜率：  
   - `dh/dt ≈ (h_{i+1}-h_i)/(t_{i+1}-t_i)`  
   - 泵关区间可直接得到该区间平均出流量：  
     `f_bar_i ≈ -A*(h_{i+1}-h_i)/(t_{i+1}-t_i)`。  
   这一步可以给参数初值，但直接差分较敏感（会放大观测噪声）。

4. **为何采用“积分拟合”而不是“差分直接算”**  
   为了更稳定，我们不直接用点差分算瞬时流量，而是用积分式：
   - `h_hat(t)=h0 + (1/A)*(q_p*P(t) - ∫_0^t f(tau)dtau)`  
   - 其中 `P(t)` 是累计泵水时长。  
   这样把反演问题转化为“拟合整条水位曲线”，对噪声更稳健，也更容易在泵水段恢复 `f(t)`。

## 数学模型
### 1) 流出流量函数参数化
根据“每天用水分布相似、曲线光滑”，将 `f(t)` 建模为日周期傅里叶级数：

- `f(t)=c0 + Σ_{k=1..K}[ck*cos(k*w*t)+dk*sin(k*w*t)]`
- `w=2*pi/86400`

其中 `K` 为低阶谐波阶数（默认 3）。

### 2) 水位预测方程
由积分形式：

- `h_hat(t)=h0 + (1/A) * (q_p * P(t) - ∫_0^t f(tau) dtau)`

其中 `P(t)` 是 `[0,t]` 内泵水累计时长（秒），由“泵水区间”直接计算。

### 3) 参数估计
用观测水位点做最小二乘：

- `min Σ_i [h_hat(t_i)-h_i]^2`

待估参数：

- `theta = [q_p, c0, c1, d1, ..., cK, dK]`

求解方法：`scipy.optimize.least_squares`。

### 4) 估计完成后的流量计算
参数估计得到 `q_p` 和傅里叶系数后：
- 任意时刻直接代入 `f(t)` 表达式即可得到出流量；
- 也可用守恒式校核：`f(t)=u(t)*q_p-A*dh_hat/dt`。

## 方法选择与理由
- 该题本质是“由状态量（水位）反演流量”的逆问题；
- 直接拟合 `h(t)` 比先差分再拟合更稳定（差分会放大噪声）；
- 傅里叶低阶参数化可表达“日周期 + 光滑变化”，与题目假设一致；
- 估计出 `q_p` 后，泵水期间 `f(t)` 也可直接由模型给出。

## 原书做法概括（MATLAB 思路）与对比评价
### 1) 原书做法概括
从给出的代码可概括为以下步骤：

1. 读取时间与水位数据，并将表格两列拼成一列向量；
2. 做单位换算：
   - `h0 -> h(m)`；
   - `t0 -> t(h)`；
   - 由圆柱体公式计算体积 `V(t)=pi/4*D^2*h(t)`；
3. 用数值微分 `gradient(V,t)` 得到 `dV/dt`；
4. 取 `-dV/dt` 作为流出流量近似；
5. 将“泵水”对应的无效点（及其附近导数点）删除；
6. 对剩余流量散点做样条插值（`csape`），得到连续流量曲线。

其核心思想是：  
**先由水位算体积，再对体积曲线做数值求导，直接得到流量。**

### 2) 与本文方法的差异
- 原书方法：`水位 -> 体积 -> 数值导数 -> 流量`（差分/导数主导）；
- 本文方法：`给定流量参数化 -> 守恒方程积分得水位 -> 拟合水位反演流量`（积分拟合主导）。

### 3) 对比评价
- **原书方法优点**：
  - 实现直接、计算量小；
  - 不需要显式建立复杂参数模型；
  - 便于快速得到流量散点与插值曲线。
- **原书方法局限**：
  - 数值求导会放大测量噪声，对采样间隔与数据缺口敏感；
  - 泵水区间要手工剔除无效点，区间内流量需要“插值补”而非“物理反演”；
  - 难以同时估计泵流量常数 `q_p` 与出流函数 `f(t)` 的耦合关系。
- **本文方法优点**：
  - 直接拟合观测水位，避免先差分导致的不稳定；
  - 可联合估计 `q_p` 和 `f(t)`，并能自然覆盖泵水时段；
  - 容易引入“日周期、光滑性”等先验假设，结果物理解释性更强。
- **本文方法局限**：
  - 依赖模型假设（周期性、谐波阶数、正则化强度）；
  - 参数更多，调参与求解成本高于原书的直接导数法。

### 4) 实际建议
- 若目标是“快速复现教材流程与直观结果”，可用原书导数+样条法；
- 若目标是“在泵水区间也获得更稳健、可解释的流量反演”，本文积分拟合法更合适。
