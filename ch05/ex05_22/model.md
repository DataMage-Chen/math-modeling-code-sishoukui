# 例题 5.22 模型（调水调沙试验数据建模）

## 题意重述
根据表 5.14 的观测数据（每 12 小时一次）建立模型，研究：

1. 如何估计任意时刻的排沙量及总排沙量；
2. 如何确定排沙量与水流量之间的关系。

## 已知数据与符号说明
- `Q(t)`：水流量，单位 `m^3/s`；
- `C(t)`：含沙量，单位 `kg/m^3`；
- 观测时间：`6.29 8:00` 到 `7.10 20:00`，共 24 个时刻，间隔 12 小时；
- 排沙量（输沙率）定义为：
  - `S(t) = Q(t) * C(t)`，单位 `kg/s`。

## 数学模型
### 1) 任意时刻排沙量估计
分别对 `Q(t)` 与 `C(t)` 构造插值函数（如 PCHIP 或三次样条）：

- `Q_hat(t)`
- `C_hat(t)`

则任意时刻排沙量估计：

- `S_hat(t) = Q_hat(t) * C_hat(t)`。

### 2) 总排沙量估计
在试验时段 `[t0,t1]` 上积分：

- `M = ∫_{t0}^{t1} S_hat(t) dt`

其中 `M` 单位为 kg，可换算为 t 或 万t。

### 3) 排沙量与水流量关系
由观测点构造 `S_i = Q_i*C_i`，拟合经验关系。常见形式：

- 线性：`S = alpha + beta*Q`
- 二次：`S = a0 + a1*Q + a2*Q^2`
- 分段二次（按时间过程分段）：
  - 增大段（`Q: 1800 -> 2720`）：`S = p0 + p1*Q + p2*Q^2`
  - 减小段（峰值后的下降过程，如 `Q: 2650 -> 900`）：`S = q0 + q1*Q + q2*Q^2`
  - 分段规则中峰值点仅放在第一段，第二段从峰值后的第一个观测点开始。

通过误差指标（如 `R^2`）比较整体与分段模型效果。

## 方法选择与理由
- 时间插值采用 PCHIP（默认）或三次样条：
  - PCHIP 更保形，能减少振荡导致的非物理负值；
- 总量采用数值积分（梯形积分）；
- `S-Q` 关系采用线性、整体二次与分段二次对照：
  - 调水调沙过程中 `Q` 先升后降，存在“同一流量在不同时段对应不同排沙量”的可能；
  - 因此增加分段二次拟合，增强对阶段性差异（类“回线现象”）的表达能力。

## 结果与校验
- 输出任意查询时刻的 `Q_hat, C_hat, S_hat`；
- 输出总排沙量（kg/t/万t）；
- 输出 `S-Q` 关系拟合参数与 `R^2`；
- 绘制时序图与 `S-Q` 散点/拟合曲线图；
- 如与教材数值有细微差异，通常由插值方式、积分步长和容差设置差异导致。
