# 例题 5.17 模型（分段线性函数拟合）

## 题意重述
根据给定观测数据 `(x_i, y_i)`，拟合分段线性函数：

`y = a + b*x,  x < k`

`y = c + d*x,  x >= k`

其中 `a,b,c,d,k` 为待定参数，`k` 为分段点。

## 已知数据与符号说明
数据（13 组）：

- `x = [0.81, 0.91, 0.13, 0.91, 0.63, 0.098, 0.28, 0.55, 0.96, 0.96, 0.16, 0.97, 0.96]`
- `y = [0.17, 0.12, 0.16, 0.0035, 0.37, 0.082, 0.34, 0.56, 0.15, -0.046, 0.17, -0.091, -0.071]`

记拟合函数为 `f(x)`。

## 数学模型
对固定分段点 `k`，分别在左右两段做最小二乘直线拟合：

- 左段（`x<k`）：`min Σ_{x_i<k} [y_i-(a+b*x_i)]^2`
- 右段（`x_i>=k`）：`min Σ_{x_i>=k} [y_i-(c+d*x_i)]^2`

总体误差：

`SSE(k) = Σ_i [y_i - f(x_i; a,b,c,d,k)]^2`

再在候选 `k` 中选取使 `SSE(k)` 最小者。

## 方法选择与理由
- 分段点未知时，直接联合非线性拟合较不稳定；
- 对每个候选 `k`，左右段参数是线性最小二乘，求解稳定；
- 通过遍历候选 `k`（由样本 `x` 的唯一值构成）可得到全局最优分段方案（在该离散候选集合上）。

## 结果与校验
- 输出最优 `k,a,b,c,d`；
- 输出 SSE、RMSE、`R^2`；
- 输出左右段样本数，检查分段是否合理；
- 绘制散点与分段拟合曲线，直观观察拟合效果。
