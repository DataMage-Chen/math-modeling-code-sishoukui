# 例题 5.5 模型（三次样条插值求位移）

## 题意重述
已知速度曲线 `v(t)` 的 4 个观测点（表 5.4）：

- `t = [0.15, 0.16, 0.17, 0.18]`
- `v(t) = [3.5, 1.5, 2.5, 2.8]`

要求用三次样条插值估计位移：

`S = ∫[0.15,0.18] v(t) dt`

## 已知数据与符号说明
- 自变量：时间 `t`
- 因变量：速度 `v(t)`
- 插值函数：`s(t)`，为通过上述 4 点的三次样条函数
- 位移：`S = ∫ s(t) dt`（以样条函数近似真实速度曲线）

## 数学模型
1. 在各子区间 `[t_i, t_{i+1}]` 上构造三次多项式：
   - `s_i(t) = a_i(t-t_i)^3 + b_i(t-t_i)^2 + c_i(t-t_i) + d_i`
2. 满足三次样条条件：
   - 插值条件：`s(t_i)=v_i`
   - 一阶导连续：`s'(t_i-) = s'(t_i+)`
   - 二阶导连续：`s''(t_i-) = s''(t_i+)`
   - 端点边界条件（本实现默认采用 natural，可切换）
3. 位移估计：
   - `S = ∫[0.15,0.18] s(t) dt`

## 方法选择与理由
- 采用 `scipy.interpolate.CubicSpline`：
  - 直接构造分段三次样条；
  - 可稳定获得函数值、导数与定积分；
  - 相比直接全局高次多项式插值，局部性更好、振荡风险更低。
- 为与教材常见解法保持一致，代码默认边界条件设为 `not-a-knot`（仍可通过参数切换为 `natural`）。

## 结果与校验
- 校验插值误差：`max|s(t_i)-v_i|` 应接近 0；
- 输出样条积分得到的位移 `S`；
- 同时输出梯形法积分结果作为参考对照（便于理解样条积分改进量）。
