# 例题 5.10 模型（由观测点拟合小行星椭圆轨道）

## 题意重述
已知小行星在轨道平面内的 5 个观测点坐标（表 5.9），并知轨道可视为椭圆。  
设轨道一般二次曲线方程为：

`a1*x^2 + a2*x*y + a3*y^2 + a4*x + a5*y + 1 = 0`

要求根据观测数据求出轨道方程参数，并绘制轨道曲线。

## 已知数据与符号说明
- 观测点：
  - `x = [5.764, 6.286, 6.759, 7.168, 7.408]`
  - `y = [0.648, 1.202, 1.823, 2.526, 3.360]`
- 未知参数：`a = [a1,a2,a3,a4,a5]^T`。

## 数学模型
将每个观测点 `(x_i,y_i)` 代入方程，得到线性方程组：

`[x_i^2, x_i*y_i, y_i^2, x_i, y_i] * a = -1`

写成矩阵形式：

`M a = b`，其中 `b = [-1,...,-1]^T`。

用线性代数求解 `a` 后得到轨道隐式方程。

## 方法选择与理由
- 本题方程对参数 `a1~a5` 线性，适合直接用线性方程组求解；
- 若观测点多于 5 个，可自然扩展为最小二乘拟合（`lstsq`）；
- 轨道曲线采用隐式函数 `F(x,y)=0` 的等值线绘制，更直观稳定。

## 结果与校验
- 在观测点处计算残差 `F(x_i,y_i)`，应接近 0；
- 计算判别量 `Δ = a2^2 - 4*a1*a3`，若 `Δ < 0` 则为椭圆型；
- 绘制轨道曲线与观测点，检查拟合一致性。
