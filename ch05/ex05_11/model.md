# 例题 5.11 模型（带约束的经验函数拟合）

## 题意重述
已知 `x,y` 观测值（表 5.10），拟合经验函数：

`y = a*e^x + b*ln(x)`

并满足参数约束：

- `a >= 0`
- `b >= 0`
- `a + b <= 1`

## 已知数据与符号说明
按表中数据（整数）：

- `x = [3, 5, 6, 7, 4, 8, 5, 9]`
- `y = [4, 9, 5, 3, 8, 5, 8, 5]`

参数：

- `a, b`：待估计系数。

## 数学模型
采用最小二乘准则，构建约束优化模型：

`min_{a,b}  Σ_i [y_i - (a*e^{x_i} + b*ln(x_i))]^2`

`s.t.  a>=0, b>=0, a+b<=1`

## 方法选择与理由
- 模型对参数是非线性特征（`e^x, ln x`）的线性组合，目标函数为凸二次函数；
- 约束为线性不等式，整体是小规模凸约束最小二乘问题；
- 代码采用“解析最小二乘 + 可行边界枚举”方式直接求全局最优，结果与 `lsqlin` 思路一致，且不依赖迭代初值稳定性。

## 结果与校验
- 输出最优参数 `a,b` 与拟合公式；
- 输出 SSE、RMSE、`R^2`；
- 校验约束满足性（`a,b,a+b`）；
- 绘制观测点与拟合曲线，直观检查拟合效果。
