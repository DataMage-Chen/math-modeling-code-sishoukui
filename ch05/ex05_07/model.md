# 例题 5.7 模型（双三次样条高程插值与地表面积估计）

## 题意重述
已知平面区域 `0<=x<=1400, 0<=y<=1200` 上的高程离散数据（表 5.6，单位 m）。  
要求：

1. 用双三次样条插值，计算 `x,y` 方向间隔均为 `10` 的节点高程；
2. 求该区域最大高程与最小高程；
3. 绘制等高线图和三维网格图；
4. 估计该区域地表面积。

## 已知数据与符号说明
- 原始网格坐标：
  - `x = 0,100,200,...,1400`
  - `y = 0,100,200,...,1200`
- 原始高程：`z_ij = z(x_j, y_i)`（单位 m）。
- 插值曲面记为 `s(x,y)`。

## 数学模型
1. **双三次样条插值**  
   在规则网格上构造双三次样条曲面 `s(x,y)`，使其通过全部原始测点。

2. **间隔 10 的节点高程**  
   在
   - `x_k = 0,10,20,...,1400`
   - `y_l = 0,10,20,...,1200`
   上计算 `s(x_k, y_l)`。

3. **极值估计**  
   在上述 `10` 间隔网格上搜索：
   - `z_max = max s(x_k,y_l)`
   - `z_min = min s(x_k,y_l)`。

4. **地表面积估计**  
   由曲面面积公式：
   `A = ∬ sqrt(1 + (∂s/∂x)^2 + (∂s/∂y)^2) dxdy`
   在区域 `[0,1400]x[0,1200]` 上做数值积分得到近似表面积。

## 方法选择与理由
- 采用 `scipy.interpolate.RectBivariateSpline`：
  - 适用于规则网格的双变量三次样条；
  - 可直接计算插值值与一阶偏导，便于面积积分。
- 绘图采用 `matplotlib`：
  - 等高线图展示地形分布；
  - 三维曲面图直观展示高程形态。

## 结果与校验
- 校验样条在原始测点处误差 `max|s(x_i,y_j)-z_ij|` 应接近 0；
- 输出 `10` 间隔网格规模、最大/最小高程与坐标；
- 输出估计地表面积（m² 与 km²）。
- 由于 MATLAB 与 Python（SciPy）在双样条边界处理、数值积分策略及默认容差上的实现细节存在差异，计算结果与原书示例可能有小幅数值偏差，属于正常范围。
