# 习题 5.5 模型（三次多项式拟合与噪声影响）

## 题意重述
给定三次多项式

- `f(x) = a3*x^3 + a2*x^2 + a1*x + a0`
- `a3=8, a2=5, a1=2, a0=-1`

在区间 `[-6,6]` 上等步长取 `100` 个观测点 `x_i`，并计算 `y_i=f(x_i)`。完成两项任务：

1. 用 `(x_i,y_i)` 拟合三次多项式；
2. 构造带噪声数据 `tilde_y_i = y_i + eps_i`，其中 `eps_i ~ N(0,1)`，再用 `(x_i,tilde_y_i)` 拟合三次多项式。

## 已知数据与符号说明
- 真实函数：`f(x)=8x^3+5x^2+2x-1`
- 节点：`x_i, i=1,...,100`
- 无噪声观测：`y_i=f(x_i)`
- 有噪声观测：`tilde_y_i=y_i+eps_i`
- 拟合函数（无噪声）：`hat_f_clean(x)`
- 拟合函数（有噪声）：`hat_f_noise(x)`

## 数学模型
### 1) 无噪声数据三次拟合
求参数 `beta=[b3,b2,b1,b0]` 使

- `min Σ_i (y_i - (b3*x_i^3+b2*x_i^2+b1*x_i+b0))^2`

### 2) 有噪声数据三次拟合
求参数 `gamma=[c3,c2,c1,c0]` 使

- `min Σ_i (tilde_y_i - (c3*x_i^3+c2*x_i^2+c1*x_i+c0))^2`

## 方法选择与理由
- 使用最小二乘（`numpy.polyfit`）直接拟合三次多项式；
- 对比两组拟合系数与真值系数，直观看噪声对参数估计的影响；
- 绘图展示无噪声/有噪声场景下拟合曲线差异。
