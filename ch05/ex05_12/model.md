# 例题 5.12 模型（指数衰减经验公式拟合）

## 题意重述
研究单分子化学反应速度时，给出观测数据 `(t_i, y_i)`（表 5.11）：

- `t = [3, 6, 9, 12, 15, 18, 21, 24]`
- `y = [57.6, 41.9, 31.0, 22.7, 16.6, 12.2, 8.9, 6.5]`

要求建立经验公式：

`y = k * exp(m*t)`，

并估计参数 `k,m`。

## 已知数据与符号说明
- `t`：实验开始后的时间；
- `y`：时刻 `t` 的反应物量；
- `k,m`：待估参数。

## 数学模型
对模型两边取对数（`y>0`）：

`ln(y) = ln(k) + m*t`

令：

- `Y = ln(y)`
- `A = ln(k)`

则转化为线性回归：

`Y = A + m*t`

通过最小二乘求 `A,m`，再还原：

- `k = exp(A)`。

## 方法选择与理由
- 原模型是指数形式，取对数后可转为线性拟合，计算简单、可解释性强；
- 斜率 `m` 可解释为指数衰减（或增长）速率；
- 也可扩展做原始尺度的非线性最小二乘对照。

## 结果与校验
- 输出估计参数 `k,m` 与经验公式；
- 在对数尺度给出 `R^2`、RMSE；
- 在原始尺度给出预测值与残差，并绘制拟合曲线；
- 检查 `m` 的符号是否符合反应物衰减趋势（应为负）。
