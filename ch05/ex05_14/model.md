# 例题 5.14 模型（模拟数据拟合函数 `z=a+b*ln(x)+c*y`）

## 题意重述
利用模拟数据拟合经验函数：

`z = a + b*ln(x) + c*y`

并估计参数 `a,b,c`。

## 已知数据与符号说明
- 自变量：`x,y`（其中要求 `x>0`，以保证 `ln(x)` 有定义）；
- 因变量：`z`；
- 参数：`a,b,c`（待估计）；
- 数据来源：本题用代码生成可复现实验数据（含可控噪声）。

## 数学模型
该模型对参数是线性的，可写成：

`z_i = a + b*ln(x_i) + c*y_i + eps_i`

其中 `eps_i` 为噪声项。令设计矩阵：

`X = [1, ln(x), y]`

则最小二乘问题为：

`min_theta ||X*theta - z||_2^2`, `theta=[a,b,c]^T`

可直接用线性最小二乘求解。

## 方法选择与理由
- 由于参数线性，最小二乘法计算稳定、实现简洁；
- 用模拟数据可验证拟合方法的有效性（可与“真实参数”对照）；
- 通过绘图观察样本点与拟合曲面的匹配程度。

## 结果与校验
- 输出拟合参数 `a_hat,b_hat,c_hat`；
- 输出 SSE、RMSE、`R^2`；
- 输出参数相对真实值误差（本题可得）；
- 绘制三维散点与拟合曲面图、观测-预测对比图。
