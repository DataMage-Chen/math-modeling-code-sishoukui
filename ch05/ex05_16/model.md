# 例题 5.16 模型（模拟数据拟合二阶傅里叶级数）

## 题意重述
先用函数

`y = 2*cos(2x) + 6*sin(2x)`

生成模拟数据，再用如下二阶傅里叶级数拟合：

`f(x) = a0 + Σ_{k=1}^2 [a_k*cos(k*w*x) + b_k*sin(k*w*x)]`

其中要求 `w = 1`（通过参数上下界固定）。

## 已知数据与符号说明
- 自变量：`x`（模拟采样点）；
- 因变量：`y`（由目标函数生成，可加噪声）；
- 参数向量：`θ=[a0,a1,a2,b1,b2,w]`；
- 约束：`w` 固定为 1（可用 `Lower=Upper=1` 等价实现）。

## 数学模型
构造最小二乘拟合问题：

`min_θ Σ_i [y_i - f(x_i; θ)]^2`

并施加约束：

`w = 1`。

固定 `w=1` 后，模型对 `a0,a1,a2,b1,b2` 线性，可直接线性最小二乘求解。

## 方法选择与理由
- 题目强调“通过上下界固定参数”，代码中给出与该思想一致的固定 `w=1` 处理；
- 在 `w` 固定时，用线性最小二乘比通用非线性拟合更稳定、更可解释；
- 可直接验证恢复出的系数是否接近真实模型（理论上应有 `a2≈2,b2≈6`，其他项近 0）。

## 结果与校验
- 输出拟合系数 `a0,a1,a2,b1,b2,w`；
- 输出 SSE、RMSE、`R^2`；
- 绘制模拟数据与拟合曲线；
- 打印系数与理论值偏差，用于验证识别精度。
