# 例题 5.6 模型（边界插值求国土面积与周长）

## 题意重述
已知某国地图边界的测量数据（单位：mm）：

- 在一组 `x` 位置上，给出南边界 `y1(x)` 与北边界 `y2(x)`；
- 地图比例尺：`18 mm` 对应 `40 km`。

要求根据测量数据估计：

1. 国土近似面积；
2. 边界近似长度（周长）；
3. 并将面积结果与精确值 `41288 km^2` 比较。

## 已知数据与符号说明
- `x_i`：沿东西方向采样位置（mm）；
- `y1_i`：南边界测量值（mm）；
- `y2_i`：北边界测量值（mm）；
- 比例尺换算系数：
  - 长度：`k_L = 40/18 (km/mm)`；
  - 面积：`k_A = k_L^2 (km^2/mm^2)`。

## 数学模型
将南、北边界分别插值为函数 `s1(x), s2(x)`，则：

1. **面积模型**
   - 地图面积（mm²）：
     `A_map = ∫[x_min,x_max] (s2(x)-s1(x)) dx`
   - 实际面积（km²）：
     `A = A_map * k_A`

2. **周长模型**
   - 上、下边界弧长：
     - `L_top = ∫ sqrt(1 + (s2'(x))^2) dx`
     - `L_bottom = ∫ sqrt(1 + (s1'(x))^2) dx`
   - 左右端闭合段（若端点不重合）：
     - `L_left = |y2(x_min)-y1(x_min)|`
     - `L_right = |y2(x_max)-y1(x_max)|`
   - 地图周长（mm）：
     `L_map = L_top + L_bottom + L_left + L_right`
   - 实际周长（km）：
     `L = L_map * k_L`

## 方法选择与理由
- 主方法：三次样条插值（`CubicSpline`），获得平滑边界及导数，便于弧长积分。
- 对照方法：分段线性（折线）近似，用于给出直观基准结果。
- 数值积分：
  - 面积：样条自带积分；
  - 弧长：对 `sqrt(1+(s'(x))^2)` 做数值积分。

## 结果与校验
- 输出样条法与折线法的面积、周长估计；
- 对面积计算绝对误差与相对误差（相对 `41288 km^2`）；
- 可视化边界曲线，检查几何形状与数据一致性。
- 由于 MATLAB 与 Python（SciPy）在样条边界处理、数值积分细节与默认容差上的实现存在细微差异，计算结果与书中示例可能有小幅出入，属于正常数值误差范围。
