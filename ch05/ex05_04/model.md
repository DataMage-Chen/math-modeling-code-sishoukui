# 例题 5.4 模型（插值加工轨迹）

## 题意重述
机床加工中，已知一组离散数据点 `(x,y)`（表 5.3），需要通过插值构造加工曲线。  
要求：

1. 在步长为 `0.1` 的 `x` 网格上给出对应坐标；
2. 画出插值曲线；
3. 求 `x=0` 处曲线斜率；
4. 求区间 `13<=x<=15` 内 `y` 的最小值；
5. 分别使用三种方法：拉格朗日插值、分段线性插值、三次样条插值。

## 已知数据与符号说明
表 5.3 数据点：

- `x = [0, 3, 5, 7, 9, 11, 12, 13, 14, 15]`
- `y = [0, 1.2, 1.7, 2.0, 2.1, 2.0, 1.8, 1.2, 1.0, 1.6]`

记三种插值函数分别为：

- `P_L(x)`：拉格朗日插值多项式；
- `P_{PL}(x)`：分段线性插值函数；
- `P_S(x)`：三次样条插值函数。

## 数学模型
1. **插值条件**：各方法都满足 `P(x_i)=y_i`。
2. **离散加工轨迹**：在 `x_k = 0 + 0.1*k` 上计算 `P(x_k)`。
3. **斜率计算**：
   - 拉格朗日：由插值多项式导数计算 `P_L'(0)`；
   - 分段线性：取右导数 `P_{PL}'(0+)`（第一段斜率）；
   - 三次样条：由样条导数计算 `P_S'(0)`。
4. **区间最小值**：在 `[13,15]` 稠密网格上搜索 `min P(x)`。

## 方法选择与理由
- **拉格朗日**：使用重心拉格朗日实现，数值稳定，适合全局多项式插值。
- **分段线性**：结构最简单、局部性强，便于解释加工路径折线近似。
- **三次样条**：平滑性好（函数及一、二阶导连续），更符合加工轨迹连续性需求。

## 结果与校验
- 校验三种方法在原始节点处误差 `max|P(x_i)-y_i|` 应接近 0；
- 输出三种方法在 `x=0` 斜率与 `[13,15]` 区间最小值；
- 图中对比三条曲线及原始数据点，直观观察不同插值方式差异。
