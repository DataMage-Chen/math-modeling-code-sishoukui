# 例题 5.18 模型（非线性参数拟合）

## 题意重述
利用表 5.13 的观测数据，拟合函数

`y = exp(-k1*x1) * sin(k2*x2) + x3^2`

中的参数 `k1, k2`。

## 已知数据与符号说明
- 自变量：`x1, x2, x3`
- 因变量：`y`
- 待估参数：`k1, k2`
- 共 25 组观测样本（由表 5.13 给出）。

## 数学模型
建立非线性最小二乘模型：

`min_{k1,k2} Σ_i [ y_i - (exp(-k1*x1_i)*sin(k2*x2_i) + x3_i^2 ) ]^2`

记残差：

`r_i(k1,k2) = exp(-k1*x1_i)*sin(k2*x2_i) + x3_i^2 - y_i`

则目标为：

`min Σ_i r_i^2`。

## 方法选择与理由
- 该模型对 `k1,k2` 都是非线性的，采用 `scipy.optimize.least_squares` 求解；
- 为降低局部极值影响，使用多初值重启并取 SSE 最小结果；
- 拟合后通过残差、`R^2`、观测-预测对比图评估模型表现。

## 结果与校验
- 输出最优参数 `k1,k2` 与 SSE、RMSE、`R^2`；
- 输出每个样本的预测值与残差；
- 绘制观测-预测散点图与残差图；
- 若与书中结果存在轻微差异，通常来源于非线性优化初值/容差/实现细节差别。
- 本题属于非线性参数估计问题，目标函数可能存在多个局部极小值，对初值较敏感，求解结果可能不稳定；因此建议采用多初值重启、收敛容差复核与结果交叉验证。
