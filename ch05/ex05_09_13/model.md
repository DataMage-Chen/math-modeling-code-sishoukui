# 例题 5.9 模型（线性经验公式拟合）

## 题意重述
为测量刀具磨损速度，实验每隔固定时间测一次刀具厚度，得到数据：

- `t_i = [0,1,2,3,4,5,6,7]`
- `y_i = [27.0,26.8,26.5,26.3,26.1,25.7,25.3,24.8]`

要求根据实验数据建立 `y` 与 `t` 的经验公式：

`y = a t + b`。

## 已知数据与符号说明
- `t`：时间（实验序号/小时等间隔）
- `y`：刀具厚度观测值
- `a`：线性变化率（斜率）
- `b`：初始厚度估计（截距）

## 数学模型
采用最小二乘法拟合线性模型：

`min_{a,b}  Σ_{i=1}^n [y_i - (a t_i + b)]^2`

得到参数估计 `a_hat, b_hat` 后，经验公式为：

`y_hat(t) = a_hat t + b_hat`。

## 方法选择与理由
- 该题给定模型形式就是一次函数，最小二乘线性回归是最直接、可解释性最强的方法。
- 斜率 `a_hat` 可直接解释为“单位时间平均厚度变化量”。

## 结果与校验
- 输出拟合参数 `a_hat, b_hat` 与经验公式；
- 输出拟合优度指标：`R^2`、RMSE；
- 打印各观测点预测值与残差，检查是否存在明显系统偏差；
- 可选绘制散点与拟合直线图辅助判断拟合效果。
