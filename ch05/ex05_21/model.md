# 例题 5.21 模型（`cos x` 在子空间 `Span{1,x^2,x^4}` 上的最佳平方逼近）

## 题意重述
求函数 `f(x)=cos x` 在区间 `[-pi/2, pi/2]` 上、子空间

`H = Span{1, x^2, x^4}`

中的最佳平方逼近多项式。

## 已知数据与符号说明
- 目标函数：`f(x)=cos x`
- 区间：`I=[-pi/2, pi/2]`
- 基函数：`phi0=1, phi1=x^2, phi2=x^4`
- 逼近多项式：`p(x)=c0 + c1*x^2 + c2*x^4`

## 数学模型
在内积空间 `L2(I)` 中，最佳平方逼近满足：

`min_{c0,c1,c2} ||f-p||_2^2 = min ∫_I (f(x)-p(x))^2 dx`

根据正规方程（正交投影）：

`<f-p, phij> = 0,  j=0,1,2`

可得线性方程组：

`G c = b`

其中：

- `G_ij = <phii, phij> = ∫_I phii(x)*phij(x) dx`
- `b_i = <f, phii> = ∫_I cos(x)*phii(x) dx`

解得 `c=[c0,c1,c2]^T` 即为所求。

## 方法选择与理由
- 该问题是典型 Hilbert 空间正交投影问题；
- 基函数维数仅为 3，正规方程是 `3x3` 线性系统，计算稳定、可解析表达；
- 结果可通过“残差与基函数正交”进行校验。

## 结果与校验
- 输出最优逼近多项式 `p(x)`；
- 检验 `|<f-p,1>|, |<f-p,x^2>|, |<f-p,x^4>|` 是否接近 0；
- 在网格上计算近似误差并绘图对比 `cos x` 与 `p(x)`。
