# 例题 5.15 模型（非线性经验函数拟合）

## 题意重述
利用表 5.12 的观测数据，拟合经验函数：

`z = a*exp(b*x1) + c*x2^2`

求参数 `a,b,c` 的估计值。

## 已知数据与符号说明
- 自变量：`x1, x2`
- 因变量：`z`
- 观测数据（8 组）：
  - `x1 = [6,2,6,7,4,2,5,9]`
  - `x2 = [4,9,5,3,8,5,8,2]`
  - `z  = [14.2077,39.3622,17.8077,11.8310,32.8618,16.9622,33.0941,11.1737]`
- 待估参数：`a,b,c`。

## 数学模型
建立非线性最小二乘模型：

`min_{a,b,c}  Σ_i [z_i - (a*exp(b*x1_i) + c*x2_i^2)]^2`

由此得到参数估计 `a_hat,b_hat,c_hat`，并形成拟合函数：

`z_hat = a_hat*exp(b_hat*x1) + c_hat*x2^2`。

## 方法选择与理由
- 该模型对 `a,c` 线性、对 `b` 非线性，属于非线性回归；
- 使用 `scipy.optimize.least_squares` 求解，适合小规模参数估计问题；
- 通过多初值重启可降低局部收敛风险，提高结果稳定性。

## 结果与校验
- 输出参数估计值与拟合公式；
- 输出 SSE、RMSE、`R^2`；
- 打印每个观测点的预测值与残差；
- 绘制观测-预测对比图与三维点图，检查拟合效果。
