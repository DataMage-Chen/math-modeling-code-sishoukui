# 习题 5.7 模型（二维非线性函数反拟合）

## 题意重述
给定函数

- `f(x,y)=a*x*y/(1+b*sin(x))`

取模拟数据：

- `x = linspace(-6,6,30)`
- `y = linspace(-6,6,40)`
- `(X,Y)=meshgrid(x,y)`
- 真参数 `a=2, b=3`
- `Z = f(X,Y)`

利用数据 `(x,y,z)` 反向估计参数，重建函数 `hat_f(x,y)`。

## 已知数据与符号说明
- 自变量网格点：`(x_i,y_j)`
- 观测值：`z_ij = f(x_i,y_j)`
- 待估参数：`a,b`
- 拟合函数：`hat_f(x,y)=a*x*y/(1+b*sin(x))`

## 数学模型
采用最小二乘参数识别：

- `min_{a,b} Σ_{i,j} [hat_f(x_i,y_j)-z_ij]^2`

并给出两种实现方式：

1. 非线性最小二乘（直接对模型残差优化）；
2. 代数重排后的线性最小二乘（对比验证）：
   - `z(1+b*sin x)=a*x*y`
   - `a*(x*y) - b*(z*sin x) = z`

## 方法选择与理由
- 非线性最小二乘对应题目“反拟合函数”的直接做法；
- 线性化方程可作为交叉校验，便于验证参数恢复精度；
- 输出参数误差与拟合误差指标（SSE、RMSE、`R^2`）。

## 结果与校验
- 输出两种方法估计参数 `a,b`；
- 与真值 `(2,3)` 对比；
- 输出拟合指标；
- 绘制观测曲面与拟合曲面对比图，以及“观测值-预测值”散点对比图。

## 说明
- 本题按弧度制计算 `sin(x)`（与 `numpy.sin` 一致）；
- 若 `1+b*sin(x)` 过接近 0，会导致数值不稳定，可设置阈值剔除极端点。
