# 习题 5.1 模型（三次样条插值与积分比较）

## 题意重述
在区间 `[0,10]` 上等间距取 `1000` 个点 `x_i`，并计算

- `g(x)=((3x^2+4x+6)/(x^2+8x+6))*sin(x)`

在这些点上的函数值 `y_i=g(x_i)`。基于观测点 `(x_i,y_i)` 构造三次样条插值函数 `hat_g(x)`，并完成：

1. 绘制 `g(x)` 与 `hat_g(x)` 图形；
2. 计算并比较 `∫[0,10] g(x)dx` 与 `∫[0,10] hat_g(x)dx`。

## 已知数据与符号说明
- 区间：`[a,b]=[0,10]`
- 节点数：`n=1000`
- 等距节点：`x_i = a + (i-1)h, h=(b-a)/(n-1), i=1,...,n`
- 观测值：`y_i=g(x_i)`
- 三次样条插值函数：`hat_g(x)`，满足 `hat_g(x_i)=y_i`。

## 数学模型
### 1) 数据生成
由解析函数直接生成样本：

- `y_i = g(x_i)`。

### 2) 三次样条插值
在节点集 `{x_i}` 上构造三次样条 `hat_g(x)`：

- 分段三次多项式；
- 满足插值条件 `hat_g(x_i)=y_i`；
- 在内部节点满足一阶、二阶导连续。

### 3) 积分计算
- 真函数积分：`I_g = ∫[0,10] g(x)dx`（数值积分高精度计算）；
- 样条积分：`I_s = ∫[0,10] hat_g(x)dx`（由样条函数积分得到）。

并比较：

- `|I_g-I_s|` 与相对误差 `|I_g-I_s|/|I_g|`。

## 方法选择与理由
- 插值采用 `scipy.interpolate.CubicSpline`，直接构造三次样条，稳定且高效；
- 真函数积分采用 `scipy.integrate.quad`；
- 样条积分直接调用样条对象积分接口，避免额外离散误差。

## 结果与校验
- 节点插值误差 `max_i |hat_g(x_i)-y_i|` 应接近机器精度；
- 输出 `I_g`、`I_s`、绝对误差与相对误差；
- 图形中对比 `g(x)` 与 `hat_g(x)`，并可附加误差曲线辅助观察。
