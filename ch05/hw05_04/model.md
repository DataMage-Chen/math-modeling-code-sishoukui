# 习题 5.4 模型（最小二乘线性经验公式）

## 题意重述
某种合金的含铬量百分比为 `p(%)`，其熔解温度为 `theta(°C)`。已知观测数据：

- `p = [36.9, 46.7, 63.7, 77.8, 84.0, 87.5]`
- `theta = [181, 197, 235, 270, 283, 292]`

要求用最小二乘法建立 `theta` 与 `p` 的经验公式：

- `theta = a*p + b`

## 已知数据与符号说明
- `p_i`：第 `i` 个样本的含铬量（%）；
- `theta_i`：第 `i` 个样本的熔解温度（°C）；
- `a,b`：待估参数；
- 预测值：`hat_theta_i = a*p_i + b`。

## 数学模型
采用一元线性回归（最小二乘）：

- 目标函数  
  `min Σ_i (theta_i - (a*p_i + b))^2`

可写成矩阵形式：

- `X = [[p_1,1],...,[p_n,1]]`
- `y = [theta_1,...,theta_n]^T`
- `min ||Xa - y||_2^2`，其中 `a=[a,b]^T`

## 方法选择与理由
- 题目明确要求最小二乘法，线性模型可直接用正规方程或 `lstsq` 稳定求解；
- 同时输出 `R^2`、RMSE、残差，便于判断线性经验公式拟合质量。

## 结果与校验
- 输出参数 `a,b` 及经验公式；
- 输出拟合指标：SSE、RMSE、`R^2`；
- 输出各样本点预测值与残差；
- 可视化散点与回归直线，检查拟合趋势是否合理。
