# 习题 5.3 模型（线性插值与三次样条插值）

## 题意重述
已知温度与过热蒸汽体积数据：

- `T = [700, 720, 740, 760, 780]`
- `V = [0.0977, 0.1218, 0.1406, 0.1551, 0.1664]`

要求：

1. 分别用线性插值与三次样条插值估计 `T=750` 与 `T=770` 时的体积 `V`；
2. 在同一图中画出线性插值函数与三次样条插值函数。

## 已知数据与符号说明
- 自变量（温度）：`T_i`
- 因变量（体积）：`V_i`
- 线性插值函数：`V_lin(T)`
- 三次样条插值函数：`V_spline(T)`

## 数学模型
### 1) 线性插值
在每个相邻节点区间 `[T_i, T_{i+1}]` 上，用一次函数连接：

- `V_lin(T) = V_i + (V_{i+1}-V_i)/(T_{i+1}-T_i) * (T-T_i)`

### 2) 三次样条插值
构造分段三次函数 `V_spline(T)`，满足：

- 插值条件：`V_spline(T_i)=V_i`
- 内节点处一阶导与二阶导连续

## 方法选择与理由
- 线性插值直观、实现简单，适合快速估计；
- 三次样条具有更高平滑性，通常能给出更自然的曲线形态；
- 两者在同一图展示，便于观察估计差异。

## 结果与校验
- 输出 `T=750, 770` 在两种方法下的估计值；
- 绘制散点（原始数据）+ 线性插值曲线 + 三次样条曲线；
- 可输出两种方法在查询点的差值用于比较。
