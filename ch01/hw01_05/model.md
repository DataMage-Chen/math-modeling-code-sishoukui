# 习题 1.5 模型

## 题意重述
某部门在未来 5 年内可对项目 `A、B、C、D` 投资，初始资金为 `10` 万元。各项目规则如下：

- 项目 `A`：第 1~4 年年初可投，至“次年末”回收本利 `115%`；
- 项目 `B`：第 3 年年初可投，至第 5 年末回收本利 `125%`，且投资额不超过 `4` 万元；
- 项目 `C`：第 2 年年初可投，至第 5 年末回收本利 `140%`，且投资额不超过 `3` 万元；
- 项目 `D`：第 1~5 年年初均可购买公债，于当年末回收本利 `106%`。

要求确定各年投资额，使第 5 年末资金本利总额最大。

## 决策变量
均以“万元”为单位，且均为非负连续变量：

- `a_t`：第 `t` 年年初投入项目 `A` 的资金，`t=1,2,3,4`；
- `b`：第 3 年年初投入项目 `B` 的资金；
- `c`：第 2 年年初投入项目 `C` 的资金；
- `d_t`：第 `t` 年年初投入项目 `D`（公债）的资金，`t=1,2,3,4,5`。

## 目标函数
最大化第 5 年末资金总额：

- `max z = 1.06*d5 + 1.15*a4 + 1.25*b + 1.40*c`

## 约束条件
1. 逐年资金平衡（年初可投金额 = 当年可支配金额）：
   - 第 1 年：`a1 + d1 = 10`
   - 第 2 年：`a2 + c + d2 = 1.06*d1`
   - 第 3 年：`a3 + b + d3 = 1.06*d2 + 1.15*a1`
   - 第 4 年：`a4 + d4 = 1.06*d3 + 1.15*a2`
   - 第 5 年：`d5 = 1.06*d4 + 1.15*a3`

2. 项目投资上限：
   - `b <= 4`
   - `c <= 3`

3. 非负性：
   - `a_t, b, c, d_t >= 0`

## 说明
- 因为项目 `D` 每年都可投资且收益率为正，最优解下资金不会闲置，所以资金平衡可直接写成等式。
- 本题是线性规划（LP），可直接用 Gurobi 求解。
