# 例题 1.9 模型

## 题意重述
根据题面给出的 4 种资产数据（表 1.4）构建投资组合。公司有总资金 `M`（本实现默认 `M=1000` 元，可在代码中修改），可在银行和 4 种资产之间分配：

- 银行年收益率（本周期收益率）`r0=5%`，无风险、无交易费；
- 资产 `Si` 的平均收益率为 `ri`，风险损失率为 `qi`；
- 购买资产 `Si` 的交易费率为 `pi`，且当 `0 < xi <= ui` 时按 `ui` 计费，不购买时不收费。

目标是“收益尽可能大、总体风险尽可能小”。总体风险按各资产风险额 `qi*xi` 的最大值度量。

## 决策变量
- `x0 >= 0`：存入银行的资金；
- `xi >= 0`：投资到资产 `Si` 的资金，`i=1,2,3,4`；
- `yi ∈ {0,1}`：是否购买资产 `Si`；
- `ti >= 0`：手续费计费基数，满足 `ti = max(xi, ui*yi)`；
- `ci >= 0`：资产 `Si` 的手续费，`ci = pi*ti`；
- `z >= 0`：组合总体风险，`z = max_i(qi*xi)`。

## 目标函数
这是双目标模型：

1. 最大化收益
   - `R = r0*x0 + Σ(ri*xi)`
2. 最小化总体风险
   - `z`

实现时采用 `ε-约束法`：给定风险上限 `z <= α`，在该风险水平下最大化收益；扫描多个 `α` 得到收益-风险折中解（Pareto 点）。

## 约束条件
1. 资金平衡（手续费占用本金）  
   `x0 + Σ(xi + ci) = M`

2. 不买则不能投（逻辑约束）  
   `yi=0 => xi=0`（代码中优先使用 Gurobi 指示约束）

3. 手续费分段规则  
   `ti = max(xi, ui*yi)`  
   `ci = pi*ti`

4. 总体风险定义  
   `z = max_i(qi*xi)`

## 说明
- 题面未给总资金 `M`，代码中给出一组具体数值 `M=1000` 元，便于直接运行；
- 优先使用 Gurobi 一般约束（`addGenConstrMax`、`addGenConstrIndicator`）；
- 若关闭一般约束，则自动退化为等价线性化形式（MILP）。
