# 习题 1.3 模型

## 题意重述
某厂生产 3 种产品 `I, II, III`，每件产品都要经过 `A`、`B` 两道工序。  
设备分组如下：

- `A` 工序设备：`A1, A2`
- `B` 工序设备：`B1, B2, B3`

加工兼容性：

- 产品 `I`：可在 `A1/A2` 和 `B1/B2/B3` 上加工；
- 产品 `II`：可在 `A1/A2` 上加工，`B` 工序只能在 `B1` 上加工；
- 产品 `III`：只能在 `A2` 和 `B2` 上加工。

已知各设备加工不同产品的单位工时、设备有效台时、满负荷设备费用、原料费和销售单价，要求制定最优生产计划使利润最大。

## 决策变量
- `x_A1_I, x_A1_II, x_A2_I, x_A2_II, x_A2_III`：A 工序在各设备上的加工件数；
- `x_B1_I, x_B1_II, x_B2_I, x_B2_III, x_B3_I`：B 工序在各设备上的加工件数；
- `q_I, q_II, q_III`：三种产品的完工件数。

所有变量均为非负整数变量。

## 目标函数
最大化总利润：

- 收入：`sum(销售单价_j * q_j)`
- 原料成本：`sum(原料费_j * q_j)`
- 设备成本：`sum(单位台时费用_m * 实际占用台时_m)`

即：

- `max [sum((销售单价_j - 原料费_j) * q_j) - sum(c_m * h_m)]`

其中：

- `h_m` 为设备 `m` 的实际占用台时；
- `c_m = F_m / H_m`；
- `F_m` 为设备 `m` 的满负荷费用，`H_m` 为设备有效台时。

## “满负荷时设备费用”的含义与用法
“满负荷时设备费用”表示设备在本计划期内若运行满其有效台时 `H_m` 时的总费用 `F_m`。  
因此可折算单位台时费用：

- `c_m = F_m / H_m`

设备若实际使用 `h_m` 台时，费用按比例计为 `c_m * h_m`。  
该项在线性地进入目标函数，是成本项，不是额外的硬约束。

## 约束条件
1. 工序衔接（每种产品 A 工序总量 = B 工序总量 = 完工量）：
   - `q_I = x_A1_I + x_A2_I`
   - `q_I = x_B1_I + x_B2_I + x_B3_I`
   - `q_II = x_A1_II + x_A2_II`
   - `q_II = x_B1_II`
   - `q_III = x_A2_III`
   - `q_III = x_B2_III`

2. 设备有效台时约束：
   - `5*x_A1_I + 10*x_A1_II <= 6000`
   - `7*x_A2_I + 9*x_A2_II + 12*x_A2_III <= 10000`
   - `6*x_B1_I + 8*x_B1_II <= 4000`
   - `4*x_B2_I + 11*x_B2_III <= 7000`
   - `7*x_B3_I <= 4000`

3. 整数与非负性：
   - 所有变量 `>= 0`，且为整数。

## 说明
- 由于加工件数必须为整数，本题应建模为混合整数线性规划（MIP）。
- 设备费用按实际占用台时线性计入，整数性仅来自件数变量。
