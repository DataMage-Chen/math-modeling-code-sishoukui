# 习题 1.2 模型

## 题意重述
求解如下规划问题：

- 最小化：`z = |x1| + 2|x2| + 3|x3| + 4|x4|`

约束条件：

- `x1 - x2 - x3 + x4 = 0`
- `x1 - x2 + x3 - 3x4 = 1`
- `x1 - x2 - 2x3 + 3x4 = -1/2`

## 决策变量
- `x1, x2, x3, x4`：原始变量（可取任意实数）；
- `u1, u2, u3, u4`：绝对值辅助变量，满足 `ui >= 0`，用于表示 `|xi|`。

## 目标函数
线性化后目标函数为：

- 最小化 `z = u1 + 2u2 + 3u3 + 4u4`

## 约束条件
1. 原等式约束：
   - `x1 - x2 - x3 + x4 = 0`
   - `x1 - x2 + x3 - 3x4 = 1`
   - `x1 - x2 - 2x3 + 3x4 = -1/2`

2. 绝对值线性化约束（对每个 `i=1,2,3,4`）：
   - `xi <= ui`
   - `-xi <= ui`
   - `ui >= 0`

## 说明
- 这是线性规划（LP），可直接用 Gurobi 求解；
- Gurobi 也支持绝对值一般约束 `addGenConstrAbs`，代码中可切换两种写法。
