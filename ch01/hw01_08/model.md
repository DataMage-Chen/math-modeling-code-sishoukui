# 习题 1.8 模型（例 1.9 的模型二）

## 题意重述
在例 1.9 的投资背景下，采用书中的“模型二”：

- 在净收益至少达到给定水平 `kM` 的条件下，
- 使总体风险最小。

书中对交易费作了简化：当投资额较大时，将交易费近似按比例计为 `p_i x_i`。

## 决策变量
- `x_i >= 0`：对资产 `S_i` 的投资额，`i=0,1,2,3,4`；
  - `i=0` 表示银行存款，`r_0=0.05, p_0=0, q_0=0`；
- `z >= 0`：总体风险上界，表示 `max_{i=1..4}(q_i x_i)`。

## 目标函数
- 最小化总体风险：`min z`

## 约束条件
1. 净收益下限约束（固定收益水平）：
   - `sum_{i=0..4} (r_i - p_i) x_i >= kM`

2. 资金平衡约束（含比例交易费）：
   - `sum_{i=0..4} (1 + p_i) x_i = M`

3. 风险定义线性化：
   - `q_i x_i <= z`，`i=1,2,3,4`

4. 非负性：
   - `x_i >= 0`

## 参数说明
- `M`：总资金（默认 `10000` 元）；
- `k`：目标净收益率阈值（默认 `0.15`）；
- 数据取自表 1.4：
  - `r = [0.05, 0.28, 0.21, 0.23, 0.25]`
  - `q = [0.0, 0.025, 0.015, 0.055, 0.026]`
  - `p = [0.0, 0.01, 0.02, 0.045, 0.065]`

## 说明
- 该模型是线性规划（LP）；
- 若 `k` 过大，会导致模型不可行；代码中提供 `k` 可行区间检查；
- 代码额外提供按步长扫描 `k`（默认 `0.005`）并绘制“收益阈值-最小风险”关系图。
- 本题按例 1.9 的要求取 `M=10000`，而原书配套习题解答中将 `M` 改为 `1`，两者在尺度换算后结果一致；若将配套习题解答中的表格数值都扩大 `10000` 倍，则可与本题中的数值匹配。
