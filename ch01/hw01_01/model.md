# 习题 1.1 模型

## 题意重述
求解如下线性规划问题：

- 最大化：`z = 3x1 - x2 - x3`

约束条件：

- `x1 - 2x2 + x3 <= 11`
- `-4x1 + x2 + 2x3 >= 3`
- `-2x1 + x3 = 1`
- `x1, x2, x3 >= 0`

## 决策变量
- `x1, x2, x3`：三个连续决策变量，且均非负。

## 目标函数
- 最大化 `z = 3x1 - x2 - x3`。

## 约束条件
1. `x1 - 2x2 + x3 <= 11`
2. `-4x1 + x2 + 2x3 >= 3`
3. `-2x1 + x3 = 1`
4. `x1 >= 0, x2 >= 0, x3 >= 0`

## 说明
- 该问题是标准线性规划（LP），可直接用 Gurobi 建模求解。
- 第二条约束为“大于等于”形式，Gurobi 可直接支持，无需手工变形。
