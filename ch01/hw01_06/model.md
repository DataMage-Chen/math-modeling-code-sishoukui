# 习题 1.6 模型

## 题意重述
食品厂使用三种原料 `A、B、C` 生产两种糖果：高级奶糖与水果糖。  
两种糖果都有配比要求、销售单价，原料有供给上限和成本。  
订单要求至少生产：

- 高级奶糖 `>= 600 kg`
- 水果糖 `>= 800 kg`

在满足配比、原料供给和订单下限条件下，求最大利润。

## 决策变量
设 `x_ij` 表示原料 `i` 用于糖果 `j` 的用量（kg）：

- `i ∈ {A,B,C}`
- `j ∈ {M,F}`（`M` 表示高级奶糖，`F` 表示水果糖）

并设：

- `y_M`：高级奶糖总产量（kg）
- `y_F`：水果糖总产量（kg）

所有变量均非负。

## 目标函数
最大化总利润（销售收入 - 原料成本）：

- 收入：`24*y_M + 15*y_F`
- 成本：`20*(x_AM+x_AF) + 12*(x_BM+x_BF) + 8*(x_CM+x_CF)`

即：

- `max z = 24*y_M + 15*y_F - 20*(x_AM+x_AF) - 12*(x_BM+x_BF) - 8*(x_CM+x_CF)`

## 约束条件
1. 产量定义：
   - `y_M = x_AM + x_BM + x_CM`
   - `y_F = x_AF + x_BF + x_CF`

2. 高级奶糖配比约束：
   - `x_AM >= 0.50*y_M`
   - `x_BM >= 0.25*y_M`
   - `x_CM <= 0.10*y_M`

3. 水果糖配比约束：
   - `x_AF <= 0.40*y_F`
   - `x_BF <= 0.40*y_F`
   - `x_CF >= 0.15*y_F`

4. 原料供给约束：
   - `x_AM + x_AF <= 500`
   - `x_BM + x_BF <= 750`
   - `x_CM + x_CF <= 625`

5. 订单下限约束：
   - `y_M >= 600`
   - `y_F >= 800`

6. 非负性：
   - 所有变量 `>= 0`。

## 说明
- 本题是标准线性规划（LP）；
- 配比约束通过“原料用量与总产量的比例不等式”线性表示；
- 若想只满足订单（不超产），可将下限约束改为等式并重新求解对比。
- 注：原书习题参考中的该题解答存在数据口径差异。参考解使用了与原题不同的数据：将表 1.11 中原料 A 的可供量由 `500` 改为 `600`。若按此改动，本代码可得到与习题参考一致的结果。
