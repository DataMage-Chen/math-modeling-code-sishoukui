# 习题 1.4 模型

## 题意重述
一架货机有前舱、中舱、后舱三个货舱。每个货舱有质量上限与体积上限，且为保证飞机平衡，三个货舱装载质量应与其最大允许质量成比例。

已知货舱参数：

- 质量上限（吨）：前舱 10，中舱 16，后舱 8
- 体积上限（立方米）：前舱 6800，中舱 8700，后舱 5300

有 4 类货物可装运，参数如下：

- 可供量（吨）：`[18, 15, 23, 12]`
- 单位体积（立方米/吨）：`[480, 650, 580, 390]`
- 单位利润（元/吨）：`[3100, 3800, 3500, 2850]`

假设货物可无限细分，可在多个货舱分配，目标是使总利润最大。

## 决策变量
- `x_ij >= 0`：第 `j` 类货物分配到第 `i` 个货舱的装载量（吨）。
  - 货舱 `i ∈ {前舱, 中舱, 后舱}`
  - 货物 `j ∈ {1,2,3,4}`

## 目标函数
- 最大化总利润：
  - `max z = sum_i sum_j (p_j * x_ij)`
  - 其中 `p_j` 为第 `j` 类货物的单位利润。

## 约束条件
1. 各货舱质量约束：
   - `sum_j x_前,j <= 10`
   - `sum_j x_中,j <= 16`
   - `sum_j x_后,j <= 8`

2. 各货舱体积约束：
   - `sum_j (v_j * x_前,j) <= 6800`
   - `sum_j (v_j * x_中,j) <= 8700`
   - `sum_j (v_j * x_后,j) <= 5300`
   - 其中 `v_j` 为第 `j` 类货物单位体积。

3. 各类货物可供量约束：
   - `sum_i x_i,1 <= 18`
   - `sum_i x_i,2 <= 15`
   - `sum_i x_i,3 <= 23`
   - `sum_i x_i,4 <= 12`

4. 平衡约束（装载质量按最大允许质量同比例）：
   - `W_前 / 10 = W_中 / 16 = W_后 / 8`
   - 等价线性形式可写为：
     - `16*W_前 - 10*W_中 = 0`
     - `8*W_中 - 16*W_后 = 0`
   - 其中 `W_前 = sum_j x_前,j`，`W_中 = sum_j x_中,j`，`W_后 = sum_j x_后,j`。

## 说明
- 本题为线性规划（LP），因为货物可无限细分，决策变量取连续非负实数。
- 平衡约束是关键约束，会同时影响三个货舱的可用质量空间。
