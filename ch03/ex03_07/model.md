# 例题 3.7 模型（求非线性规划）

## 题意重述
求解如下非线性规划模型：

- `min f(x) = x1^2 + x2^2 + x3^2 + 8`

约束条件：

1. `x1^2 - x2 + x3^2 >= 0`
2. `x1 + x2^2 + x3^3 <= 20`
3. `-x1 - x2^2 + 2 = 0`
4. `x2 + 2x3^2 = 3`
5. `x1, x2, x3 >= 0`

## 决策变量
- `x1, x2, x3`：连续非负变量。
- `w`：辅助变量，表示 `w = x3^2`。

## 目标函数
最小化：

`f = x1^2 + x2^2 + w + 8`

（因为 `w = x3^2`）

## 约束条件
1. `x1^2 - x2 + w >= 0`
2. `x1 + x2^2 + x3*w <= 20`（对应 `x3^3 = x3 * x3^2 = x3*w`）
3. `-x1 - x2^2 + 2 = 0`
4. `x2 + 2w = 3`
5. `w = x3^2`
6. `x1, x2, x3 >= 0`

## 说明
- 原式含 `x3^3`，代码中用辅助变量把它改写成双线性项 `x3*w`，保持与原模型等价。
- 该模型含非凸二次等式与双线性项，属于非凸 QCP；代码中设置 `NonConvex=2` 进行全局求解。
- 同时提供“按等式约束降维后的网格校验”，用来核对求解器结果的合理性。
