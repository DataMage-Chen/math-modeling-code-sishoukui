# 例题 3.9 模型（供点与选址）

## 题意重述
已知 6 个建筑工地的位置（平面坐标 `a_i, b_i`，单位 km）和水泥日用量 `c_i`（单位 t）如下：

- 1: `(1.25, 1.25)`, `c1=3`
- 2: `(8.75, 0.75)`, `c2=5`
- 3: `(0.50, 4.75)`, `c3=4`
- 4: `(3.75, 5.00)`, `c4=7`
- 5: `(3.00, 6.50)`, `c5=6`
- 6: `(7.25, 7.75)`, `c6=11`

拟建两个料场向各工地供货，两个料场日储量上限均为 `20 t`。求两个料场的位置，使总运输吨千米数最小。

## 决策变量
- `x_k, y_k`：第 `k` 个料场坐标（`k=1,2`）。
- `q_{ik}`：料场 `k` 运往工地 `i` 的水泥量（t），`q_{ik} >= 0`。
- `d_{ik}`：料场 `k` 到工地 `i` 的距离（km），`d_{ik} >= 0`。

## 目标函数
最小化总运输吨千米：

`min Z = sum_{i=1..6} sum_{k=1..2} q_{ik} * d_{ik}`

其中 `d_{ik}` 为欧氏距离。

## 约束条件
1. 需求满足（每个工地需求必须被满足）：
   - `q_{i1} + q_{i2} = c_i,  i=1..6`
2. 料场容量（每个料场最多 20 t）：
   - `sum_i q_{ik} <= 20,  k=1,2`
3. 距离定义（欧氏距离）：
   - `(x_k-a_i)^2 + (y_k-b_i)^2 <= d_{ik}^2,  i=1..6, k=1,2`
4. 非负约束：
   - `q_{ik} >= 0, d_{ik} >= 0`

## 说明（理解与解释）
- 该模型是“连续选址 + 分配”的联合优化：既要决定料场坐标，又要决定每个工地由哪个料场（或按多少比例）供货。
- 目标函数中的 `q_{ik} * d_{ik}` 是双线性项，模型属于非凸二次规划（Nonconvex QP/QCP）。
- 代码中使用 Gurobi 的非凸求解能力（`NonConvex=2`）直接建模求解。
- 为消除两个料场标签对称性，代码可加入对称性约束（如 `x_1 <= x_2`）以加速求解，但不改变最优目标值。
- 实务上该类非凸问题求解可能较慢，本文建议默认设置求解时间上限为 `30s`；可通过命令行超参数 `--time-limit` 调整（例如 `--time-limit 60`）。
