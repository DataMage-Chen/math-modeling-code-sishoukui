# 例题 3.3 模型（求解二次规划）

## 题意重述
求解如下二次规划模型：

- `max z = -x1^2 - 0.3*x1*x2 - 2*x2^2 + 98*x1 + 277*x2`

约束条件：

1. `x1 + x2 <= 100`
2. `x1 - 2*x2 <= 0`
3. `x1, x2 >= 0`

## 决策变量
- `x1, x2`：连续非负变量。

## 目标函数
- 最大化二次目标函数 `z(x1, x2)`。

## 约束条件
1. 总量约束：`x1 + x2 <= 100`
2. 比例约束：`x1 <= 2*x2`
3. 非负约束：`x1 >= 0, x2 >= 0`

## 说明
- 该模型是连续二次规划（QP）。
- 目标函数的 Hessian 为
  `H = [[-2, -0.3], [-0.3, -4]]`，负定，因此目标函数严格凹。
- 在凸可行域上最大化严格凹函数，最优解是全局最优且唯一。
- 代码中使用 Gurobi 直接求解，并附带边界解析校验（由 `x1 + x2 = 100` 一维化后求极值）。
