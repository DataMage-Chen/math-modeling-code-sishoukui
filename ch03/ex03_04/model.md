# 例题 3.4（续例 3.3）模型（求解二次规划）

## 题意重述
求解如下二次规划模型：

- `min z = -x1^2 - 0.3*x1*x2 - 2*x2^2 + 98*x1 + 277*x2`

约束条件：

1. `x1 + x2 <= 100`
2. `x1 - 2*x2 <= 0`
3. `x1, x2 >= 0`

## 决策变量
- `x1, x2`：连续非负变量。

## 目标函数
- 最小化二次目标函数 `z(x1, x2)`。

## 约束条件
1. 总量约束：`x1 + x2 <= 100`
2. 比例约束：`x1 <= 2*x2`
3. 非负约束：`x1 >= 0, x2 >= 0`

## 说明
- 与例 3.3 的差别在于目标方向由“最大化”改为“最小化”。
- 该目标函数是严格凹函数；在凸可行域上做最小化时，模型属于非凸 QP。
- 代码中使用 Gurobi 的非凸二次能力（`NonConvex=2`）直接全局求解。
- 同时给出顶点枚举校验：由于“凹函数在凸多面体上的最小值可在极点处达到”，可用可行域顶点值对求解结果做核验。
