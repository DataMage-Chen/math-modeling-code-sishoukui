# 例题 3.8 模型（投资组合问题）

## 题意重述
已知 A、B、C 三种股票过去 12 年的年收益率数据，要求给出三种股票的投资比例（记为 `xA, xB, xC`，且比例和为 1），并从两个角度求解：

1. 在期望年收益率至少为 `15%` 的前提下，使投资组合方差最小（风险最小）。
2. 在方差不超过 `0.09` 的前提下，使期望收益最大。

## 决策变量
- `xA, xB, xC`：三种股票的投资比例，满足 `xA, xB, xC >= 0`，`xA + xB + xC = 1`。

## 目标函数
### 模型一（最小风险）
- 最小化组合方差：`min x^T Σ x`
- 同时满足：`μ^T x >= 0.15`

### 模型二（最大收益）
- 最大化组合期望收益：`max μ^T x`
- 同时满足：`x^T Σ x <= 0.09`

其中：
- `μ` 为三只股票收益率均值向量；
- `Σ` 为三只股票收益率协方差矩阵；
- 由 12 年历史数据计算得到。

## 约束条件
1. 资金全额投资：`xA + xB + xC = 1`
2. 不允许卖空：`xA, xB, xC >= 0`
3. 模型一附加收益约束：`μ^T x >= 0.15`
4. 模型二附加风险约束：`x^T Σ x <= 0.09`

## 说明（理解与解释）
- 这是经典的 Markowitz 投资组合模型：用“期望收益”衡量收益水平，用“方差（或标准差）”衡量风险。
- 协方差反映两资产收益联动关系：
  - 协方差 > 0：通常同涨同跌，分散化效果较弱；
  - 协方差 < 0：一涨一跌的可能性更强，分散化效果更明显；
  - 协方差 = 0：线性相关性弱或无明显线性相关。
- 两个子问题分别对应“给定收益看最小风险”和“给定风险看最大收益”，共同刻画风险-收益权衡关系。
- 代码默认采用样本协方差（分母 `n-1`），与教材表 3.3 的口径一致；若需改为总体协方差（分母 `n`），可使用 `--population-cov`。
- 关于样本协方差与总体协方差的选择：
  - 若历史数据被视为“从未知分布抽取的样本”，应优先使用样本协方差（`n-1`），这是金融建模最常见口径；
  - 若数据被视为“完整总体”仅做描述统计，可使用总体协方差（`n`）；
  - 两者仅差一个比例因子 `n/(n-1)`，但在含“方差上限”（如 `x^TΣx<=0.09`）的模型中会影响可行域与最优解，因此必须统一口径。
