# 例题 3.6 模型（Rosenbrock 函数极小点）

## 题意重述
求函数

`f(x) = 100(x2 - x1^2)^2 + (1 - x1)^2`

的极小点。

## 决策变量
- `x1, x2`：连续变量（无显式上下界）。
- `t`：辅助变量，定义为 `t = x2 - x1^2`。

## 目标函数
- 最小化
  `f = 100*t^2 + (1 - x1)^2`。

## 约束条件
1. 辅助变量定义约束：`t = x2 - x1^2`。

## 说明
- 原问题是典型 Rosenbrock 函数（二维形式）。
- 通过引入辅助变量 `t`，可写成带二次等式约束的模型；由于等式中含有 `x1^2`，该模型是非凸 QCP，需要启用 `NonConvex=2`。
- 从结构上也可直接看出全局最优：
  - `100(x2-x1^2)^2 >= 0`
  - `(1-x1)^2 >= 0`
  两项同时为 0 时达到最小值 0，即 `x1=1, x2=1`。
