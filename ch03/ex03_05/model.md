# 例题 3.5 模型（多元函数在 \((0,0)\) 附近的极值）

## 题意重述
求多元函数

`f(x,y) = x^3 - y^3 + 3x^2 + 3y^2 - 9x`

在 `(0,0)` 附近的极值。

## 决策变量
- `x, y`：连续变量（无显式约束）。

## 目标函数
- `f(x,y) = x^3 - y^3 + 3x^2 + 3y^2 - 9x`。

本题为无约束极值分析，需先求驻点再做二阶判别。

## 约束条件
- 无（无约束优化问题）。

## 说明
1. 一阶条件：
   - `fx = 3x^2 + 6x - 9 = 3(x+3)(x-1)`
   - `fy = -3y^2 + 6y = -3y(y-2)`
   因此驻点为 `x in {1,-3}`、`y in {0,2}` 的四个组合。
2. 二阶导数：
   - `fxx = 6x + 6`
   - `fyy = -6y + 6`
   - `fxy = 0`
3. 在 `(0,0)` 的“附近”若取一个较小邻域（例如半径 `r=1.5`），仅包含驻点 `(1,0)`，其 Hessian 正定，因此该点是局部极小点，函数值 `f(1,0) = -5`。
