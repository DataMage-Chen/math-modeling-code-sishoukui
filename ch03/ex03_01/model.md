# 例题 3.1 模型（非线性规划）

## 题意重述
求解如下非线性规划问题：

- `min f(x) = x1^2 + x2^2 - 4x1 + 4`

约束：

- `g1(x) = -x1 + x2 - 2 <= 0`
- `g2(x) = x1^2 - x2 + 1 <= 0`
- `x1 >= 0, x2 >= 0`

## 决策变量
- `x1, x2`：连续非负变量。

## 目标函数
- 最小化二次目标函数 `f(x)`。

## 约束条件
1. 线性不等式：`-x1 + x2 - 2 <= 0`
2. 二次不等式：`x1^2 - x2 + 1 <= 0`
3. 非负约束：`x1 >= 0, x2 >= 0`

## 说明
- 该问题是凸非线性规划：目标函数为凸二次函数，约束可行域为凸集。
- 从约束可得：`x1^2 + 1 <= x2 <= x1 + 2`，并且 `x1` 落在有限区间内，故最优解存在。
- 代码中使用 Gurobi 的 QCP 能力直接求解，并附带一维消元后的数值校验：
  - 最优解约为 `x1 = 0.553574`, `x2 = 1.306444`
  - 最小目标值约为 `f* = 3.798945`
